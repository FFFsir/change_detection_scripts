# AEF 变化检测平台使用说明书

本说明书面向第一次使用本工具的使用者，逐项说明平台里每个页面、每个控件「是什么、用来做什么、怎么选」。

平台有两个页面：

1. **AEF 无监督变化检测**：对 AlphaEarth Foundations (AEF) 论文补充材料 S4.1 无监督变化检测流程的本地实现，把同一瓦片的像素嵌入按论文公式 (8) 做逐像素比较，输出可交互的变化程度热力图，并与数据包里的原始光学图像并排显示。
2. **AEF 变化检测与 DW 标签对比**：对带 Dynamic World 标签的数据包，展示两期标签与官方配色、变化过渡叠加，并给出**整瓦片**的嵌入距离统计。

> **重要前提**：数据集不提供人工核实的变化参考标注，DW 标签本身是模型分类。所有结果都只能作为**探索性对照**，不能当作变化检测的准确率、精度或真值结论。

## 1. 启动

### 1.1 环境

所有依赖都装在项目虚拟环境 `.venv` 中，**必须使用虚拟环境的解释器**，不要用系统全局 Python：

```bash
.venv/Scripts/python.exe app/change_detection_webui.py
```

### 1.2 命令行参数

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `--host` | `127.0.0.1` | 监听地址。改成 `0.0.0.0` 可供局域网访问 |
| `--port` | `8080` | 监听端口 |
| `--data-root` | `data/spectral` | AEF 页的初始数据包根目录；页面里的路径输入框会显示这个值 |
| `--dw-data-root` | 仓库同级的 `AEF_DW_change_data_20261031` | DW 页的初始数据包根目录；该目录不存在时页面显示提示并回退到 `--data-root` |
| `--show` | 关闭 | 启动后自动打开浏览器窗口 |

例如：

```bash
.venv/Scripts/python.exe app/change_detection_webui.py --data-root D:/datasets/spectral_2025 --port 8081 --show
```

启动后浏览器打开 `http://127.0.0.1:8080/`，页面会自动加载默认数据根、默认瓦片、默认组合类型和默认视图，无需任何操作即可看到完整结果。

### 1.3 页面与地址

| 地址 | 页面 |
| --- | --- |
| `/` | AEF 无监督变化检测（与 `/aef` 内容一致，旧地址保持可用） |
| `/aef` | AEF 无监督变化检测 |
| `/dw` | AEF 变化检测与 DW 标签对比 |

每个页面顶部都有平台标题与两个页面入口，当前页面的入口为深色高亮。点击入口整页切换，不需要重启进程。两个页面的数据根、控件状态互不共享。

### 1.4 代码结构

入口仍是 `app/change_detection_webui.py`（命令行参数、路由与服务启动），实现拆分为 `app/webui/` 包：

| 模块 | 职责 |
| --- | --- |
| `dataset.py` | 路径解析、`Dataset`、掩膜回退、gallery 读取 |
| `render.py` | 距离、色阶、阈值量程、统计与 PNG 编码 |
| `layout.py` | 平台标题栏、导航与全局样式 |
| `aef_page.py` | AEF 无监督变化检测页 |
| `dw_data.py` | DW 标签、图例、变化过渡与整瓦片统计 |
| `dw_page.py` | DW 标签对比页 |

拆分只影响代码组织，界面行为与计算口径不变。

## 2. 数据根目录

页面最上方的「数据根目录」输入框决定当前浏览哪个数据包。修改路径后点「应用」，整个页面（瓦片列表、图像、热力图、统计）立即切换到新数据包，**不需要重启进程、也不需要刷新页面**。

### 2.1 可以填什么

输入框接受两种形态：

1. **数据包根**：目录下同时有 `tiles/` 和 `gallery/`。
   ```
   data/spectral/
   ├── tiles/<瓦片>/...
   └── gallery/index.json
   ```
2. **瓦片目录**：目录自身就是瓦片容器，其下直接是瓦片子目录（目录名不限，习惯上叫 `tiles`）。
   ```
   data/spectral/tiles/
   └── <瓦片>/...
   ```

填瓦片目录时，程序会自动把它的父目录当作数据根，因此 `gallery/` 仍然能被找到。若瓦片容器不叫 `tiles`（例如 `tiles_v2`），同样可用。

- 绝对路径和相对路径都可以；相对路径按**项目根目录**解析。
- 输入框默认显示数据根路径；若瓦片目录名不是 `tiles`，则显示该瓦片目录路径，可原样再次点「应用」。
- **不支持符号链接 / 目录联接**：瓦片目录与 `gallery/` 必须是数据根之内的真实目录。用 junction 把 `gallery/` 指到包外时，图像会按“无记录/缺图”处理，而不是读取包外文件。

### 2.2 出错时会发生什么

路径不存在、或者目录里既没有 `tiles/` 也没有瓦片子目录时，路径下方会显示红色的错误原因（例如「路径未应用：目录不存在：…」），**当前已经加载的数据保持不变**，页面不会变空白。

切换成功后，路径下方显示「当前数据根 = …（N 个瓦片）」。

### 2.3 切换后的默认行为

- 瓦片列表按新数据包重新扫描。
- 原先选中的瓦片若在新数据包中仍存在，则保留；否则自动选中新数据包中排序后的第一个瓦片。
- 组合类型保持不变；视图、帧等选择会按新瓦片的可用性自动重设。
- 所有缓存（嵌入、掩膜、图像）随数据包一起重建，不会串用上一个数据包的内容。
- 页面中的路径选择**不会被保存**到配置文件；下次启动仍以 `--data-root` 或内置默认值为准。

### 2.4 数据目录结构要求

WebUI 只读取数据根下的固定结构，不会自行推断文件位置。下面描述的是旧包（`data/spectral`）的结构；DW 数据包没有 `distance_maps/` 与 `gallery/`，其差异与回退规则见 §2.4.4。旧包中下列五项**至少**需要满足，缺任何一项都会导致该数据包无法正常浏览或图像缺失。

#### 2.4.1 最小必需结构

```
<数据根>/
├── tiles/                            # 瓦片容器（名称可为其他，但同级只能有一个候选）
│   └── <瓦片 id>/                     # 例如 C01、N11、V01
│       ├── tile_manifest.json         # 必需：类别、split、parent（坐标来源）
│       ├── embeddings/
│       │   ├── <视图>.npy              # 必需：像素嵌入
│       │   └── <视图>_index.json       # 必需：帧日期等元数据
│       └── distance_maps/
│           └── <传感器>_*.npz          # 必需：至少含 common_mask
└── gallery/
    ├── index.json                     # 必需：日期 → 图像文件的映射
    └── <瓦片>_<传感器>_<帧序号>.png      # 必需：整幅原始图
```

#### 2.4.2 逐项要求

**（1）`tiles/<瓦片 id>/`**

- 瓦片 id 直接取目录名，界面上的「瓦片」下拉就是这些目录的排序列表。
- 判定一个子目录是瓦片：其下存在 `embeddings/` 目录或 `tile_manifest.json`。其他子目录会被忽略。

**（2）`tile_manifest.json`**

数据类型为 JSON 对象。WebUI 用到以下字段：

| 字段 | 类型 | 用途 | 缺失后果 |
| --- | --- | --- | --- |
| `category` | string | 瓦片下拉里的类别标签 | 显示「未分类」 |
| `split` | string | 瓦片下拉里的数据集划分 | 显示「未标注」 |
| `parent` | string | 解析中心经纬度 | 显示「无坐标信息」 |

`parent` 需形如 `registered/tiles/C01_E121.4790_N25.1724_20240101_20241231`，即包含 `_E<经度>_N<纬度>`（西经用 `W`、南纬用 `S`）。不含该片段时（例如 `controls/tiles/V01`）按无坐标处理。

其余字段（`epochs`、`views`、`image` 等）WebUI 不读取，但建议保留以便溯源。

**（3）`embeddings/<视图>.npy`**

- 视图名必须是 `<传感器>_<波段组>` 形式，传感器前缀为 `sentinel2` 或 `landsat`；程序按这个前缀选择掩膜。
- 形状：`(帧数, 128, 128, 64)`，`float32`，每像素 64 维向量。
- 每帧的真实尺寸固定为 **128 × 128**；热力图与统计都基于这个网格，不做重采样。
- 每个像素向量应已归一化（单位长度）。零范数或含 NaN/Inf 的像素会被判为无效像素。

**（4）`embeddings/<视图>_index.json`**

帧元数据，WebUI 读取 `frames` 数组；每个元素至少要有 `date_utc`（字符串，如 `2024-02-29`），用于帧下拉标签、日期显示和「B 帧日期不得等于 A 帧」的过滤。

- `frames` 长度必须与 `.npy` 的第一维一致。
- 帧数 < 2 的视图：在「同通道跨日」和「跨日跨通道」中不会出现在视图列表（无法构成两帧比较），但在「同日跨通道」中仍可用。
- 建议同时保留 `raw_index`、`parent_raw_index`、`timestamp_ms`，便于回溯原始年度数据包。

**（5）`distance_maps/<传感器>_*.npz`**

- 文件名必须以传感器名开头（`sentinel2_*.npz` / `landsat_*.npz`）。程序按视图名前缀找对应传感器的文件，不会取目录里第一个文件，也不会跨传感器借用。
- 文件内必须有 `common_mask` 键，布尔数组，形状 `(128, 128)`。
- 同一瓦片内，同一传感器的所有视图共用同一份掩膜。
- 缺少对应传感器掩膜时该瓦片无法渲染：界面报「没有为 … 找到 common_mask」，切换数据根时会整体回滚。
- 同一 npz 里的 `C0_epoch_*`、`C1_*`、`same_modality_*` 等数值 WebUI **不使用**（距离由界面自行按论文公式计算），仅 `common_mask` 被读取。

**（6）`gallery/index.json`**

JSON 数组，每个元素形如：

```json
{"id": "C01", "source": "sentinel2", "date": "2024-02-29", "image": "spectral/gallery/C01_sentinel2_0.png"}
```

- `id` = 瓦片目录名，`source` = 传感器名，`date` = 与 `frames[i].date_utc` 完全相同，三者共同定位图像。
- `image` 是相对路径，首段为打包时的数据根目录名（默认 `spectral`）。程序会先去掉首段、按当前数据根解析，因此把整个数据包改名或复制到别处仍能正确找到图像。
- **记录与文件必须一一对应**：索引里有记录但文件不存在时，界面会显示「index.json 有该日期的记录，但文件不存在」并给出记录路径；索引里没有记录时显示「index.json 中没有该日期的记录」。两种提示不同，便于判断是数据缺失还是索引没更新。
- 索引文件缺失（`gallery/index.json` 不存在）不会阻止数据根切换，只是所有图像都按「无记录」处理。

**（7）`gallery/*.png`**

- 命名约定 `<瓦片>_<传感器>_<帧序号>.png`（帧序号为该视图内的 0 基下标）。日期到文件名的映射**只能**通过 `index.json` 完成，程序不会按日期拼文件名。
- 图像按原样完整显示，不做裁剪；界面会在内存中顺时针旋转 90° 后展示。
- 支持 Pillow 能识别的常见格式；文件损坏时会显示缺图提示，且切换数据根时会回滚。

#### 2.4.3 可选内容（WebUI 不读，但数据包可能自带）

| 路径 | 内容 |
| --- | --- |
| `tiles/<瓦片>/observations/` | 每个视图的原始观测 `npz`（`data`、`quality_mask`、时间戳等） |
| `tiles/<瓦片>/observations_original/` | 未裁剪的原始观测 |
| `tiles/<瓦片>/band_extracts/` | 按视图导出的波段数据 |
| `summary.json`、`selection.json`、`protocol.json` | 数据包级别的清单与协议说明 |
| `comparison_metrics.json`、`cross_modal_pairs.json` | 预先计算好的对照指标 |
| `gallery/<瓦片>_distance.png` | 预渲染的距离图 |

这些文件存在与否不影响 WebUI 运行，可以安全保留或删除。

#### 2.4.4 DW 数据包的差异与回退

DW 数据包（参考 `AEF_DW_change_data_20261031`）与上面的旧包结构不同，平台按下列顺序兼容，**不需要手工转换**：

| 项目 | 旧包 | DW 包 | 平台的回退规则 |
| --- | --- | --- | --- |
| 视图命名 | `sentinel2_full`、`sentinel2_nir`… | `sentinel2`、`sentinel1` | 无波段组的视图标注为「单视图（无波段组）」，不再套用分布内/分布外 |
| `distance_maps/` | 有，按传感器含 `common_mask` | 无 | 见下方掩膜回退顺序 |
| `gallery/index.json` | 有 | 无，瓦片内有 `preview.png`、`review.png` | AEF 页提示"该数据包没有 gallery/index.json"；DW 页直接显示 `preview.png` / `review.png` |
| `tile_manifest.json` | `id`、`category`、`parent` | `tile_id`、`region_id`、`before_class`… | 瓦片标签按 `category` → `region_id` → `tile_id` 回退；坐标按 `parent` → `region_id` 回退 |

**掩膜回退顺序**（界面会显示实际来源）：

1. `distance_maps/<传感器>_*.npz` 的 `common_mask`；
2. 无 `distance_maps/` 时：`land_cover/dynamic_world.npz` 的 `valid_mask`（两期取与）；
3. 再退一步：`observations/<传感器>.npz` 的 `valid_mask`（两帧取与）；
4. 都没有：全 True，界面注明"数据包未提供任何掩膜"。

注意：如果 `distance_maps/` 目录**存在**但缺少当前传感器的文件，仍按旧规则报错，不会悄悄回退——这是为了保持旧包的既有验收口径。

#### 2.4.5 规模参考（默认数据包 `data/spectral`）

| 项 | 数值 |
| --- | --- |
| 瓦片数 | 33（C01–C21、N01–N12、V01） |
| `tiles/` 体积 | 约 2.2 GB（主要是 `embeddings/*.npy`，单瓦片约 89 MB） |
| `gallery/` 体积 | 约 12 MB（137 张 PNG） |
| 视图数 | 每瓦片最多 10 个（Sentinel-2 5 个 + Landsat 5 个） |

因此**不要把 `data/` 提交进 Git 仓库**；用 `--data-root` 或界面路径指向本地数据包即可。

#### 2.4.6 自检清单

准备一个新数据包时，按顺序确认：

1. `<数据根>/tiles/<瓦片>/embeddings/` 下至少有一个 `.npy` 和同名 `_index.json`。
2. `.npy` 最后一维是 64，前三项为 `(帧数, 128, 128)`，且 `帧数` 与 `_index.json` 的 `frames` 长度一致。
3. `<数据根>/tiles/<瓦片>/distance_maps/` 下存在与视图传感器同名的 `*_*.npz`，且内含 `common_mask`，形状 `(128, 128)`。
4. `tile_manifest.json` 是合法 JSON 对象（至少含 `category`、`split`、`parent`）。
5. `gallery/index.json` 是 JSON 数组，每条记录都有 `id`/`source`/`date`/`image`。
6. 索引中每条 `image` 指向的文件真实存在。
7. 三者交叉一致：瓦片 id = 目录名 = `index.json` 的 `id`；`source` = 视图名的传感器前缀；`date` = `frames[i].date_utc`。

## 3. 组合类型

三种组合类型对应三种完全不同的比较口径，必须按分析目的选择。

| 选项 | 比较对象 | 结果含义 | 什么时候用 |
| --- | --- | --- | --- |
| **同通道跨日（同模态对照）** | 同一传感器、同一波段组（视图）在不同日期的两帧 | 高值 = 该像素的嵌入变化程度 | 判断同一模态下地表是否变化；这是最接近常规变化检测的用法 |
| **同日跨通道（跨模态基线）** | 同一传感器、同一日期、两个不同波段组 | 高值 = 通道之间的固有差异，**不代表变化** | 作为对照，量出「即使没有变化，通道差异本身有多大」 |
| **跨日跨通道（跨模态变化）** | 同一传感器、两个不同波段组、各自不同日期 | 残差 = 跨日期距离 − 同日基线 | 探索性跨模态变化检测；需结合基线一起看 |

选择组合类型后，下方控件、热力图、图像和统计会同步更新，无需刷新页面。

页面顶部和结果区都会持续显示当前组合类型的语义提示，避免把「基线差异」误读成「变化」。

## 4. 瓦片选择与坐标信息

### 4.1 瓦片选择器

下拉框列出当前数据根 `tiles/` 下的全部瓦片，每项后面附带类别和 split（数据集划分），格式为：

```
C01 · 裸地扩展／疑似地表清理 · train
```

切换瓦片会重新加载该瓦片的嵌入、掩膜与图像，并按新瓦片的可用性重设视图和帧。

### 4.2 坐标信息

瓦片选择器正下方显示当前瓦片的位置：

```
瓦片 C01
中心坐标 = 121.4790°E / 25.1724°N
原始父目录 = registered/tiles/C01_E121.4790_N25.1724_20240101_20241231
```

- **中心坐标**：从瓦片清单文件的父目录名解析出的中心经纬度，东经/北纬为正，西经/南纬用 `W`/`S` 表示。
- **原始父目录**：数据生产时记录的原始目录名，便于回溯数据来源。
- 该瓦片没有坐标信息时（例如控制组瓦片 `V01`），显示「中心坐标 = 无坐标信息」，但父目录仍会显示。

坐标只用于定位瓦片，不参与任何计算。

## 5. 视图 / 通道选择

「视图」是同一传感器下取用的波段组合，命名形如 `<传感器>_<波段组>`，例如 `sentinel2_full`、`landsat_nir`。

### 5.1 按组合类型变化的控件

- **同通道跨日**：只有一个「视图」选择器，且只列出帧数 ≥ 2 的视图（否则无法构成两帧比较）。被排除的单帧视图会在结果区说明。
- **同日跨通道 / 跨日跨通道**：有「通道 A」和「通道 B」两个选择器。
  - A 列出当前瓦片全部可用视图。
  - B 只列出与 A **同传感器**且与 A **不同**的视图。
  - 切换 A 的传感器时，B 自动重选：优先 `sentinel2_nir`，不可用时取该传感器下第一个不同于 A 的视图。
  - 跨日跨通道只列出帧数 ≥ 2 的视图，因此只有单期观测的 Landsat 视图不会出现。

### 5.2 默认值

- 同通道跨日：默认 `sentinel2_full`（若不存在则取第一个可用视图）。
- 跨通道：默认 A = `sentinel2_visible`，B = `sentinel2_nir`；不可用时回退到该瓦片第一组可用的同传感器视图对。

### 5.3 分布内 / 分布外

结果区会为每个通道标注：

- **分布内**：`full` 视图，是编码器训练时使用的完整波段组合。
- **分布外（波段消融诊断）**：只保留部分波段的视图。这类视图用于诊断波段缺失的影响，数值不能与 `full` 直接等量齐观。
- 当 A、B 一个为分布内、另一个为分布外时，额外显示「分布内 vs 分布外混合对照」。

## 6. 帧（对）选择

| 组合类型 | 控件 | 说明 |
| --- | --- | --- |
| 同通道跨日 | 「帧对」 | 帧数 = 2 时固定为第 0 帧 → 第 1 帧，不显示控件；帧数 > 2 时列出所有 `i < j` 组合，默认首帧 → 末帧 |
| 同日跨通道 | 「帧（两通道同日期）」 | 单一帧选择器，同时决定 A、B 两个通道取哪一期 |
| 跨日跨通道 | 「A 通道帧」「B 通道帧」 | A 默认首帧；B 默认最后一个日期不同于 A 的帧，可选项会自动排除与 A 参考日期相同的帧 |

帧标签格式为 `帧 <序号> · <日期>`，日期取自该视图的帧元数据。

跨日跨通道中改变 A 帧后，B 的可选项会重建，避免选到与参考日期同一天，从而保证比较的确实是「跨日」。

## 7. 残差方向与残差取值（仅跨日跨通道）

这两个选择器只在「跨日跨通道」组合下出现。

### 7.1 残差方向

记 A 的参考帧为 `ref`、B 的目标帧为 `other`：

| 选项 | 公式 | 含义 |
| --- | --- | --- |
| **正向（默认）** | `fwd = d(A_ref, B_other) − base` | 以 A 参考日期的视角看跨日期变化 |
| 反向 | `rev = d(B_ref, A_other) − base` | 以 B 参考日期的视角看跨日期变化 |
| 对称化 | `sym = (正向 + 反向) / 2` | 两个方向的平均，最稳定但会抵消方向性差异 |

其中 `base = d(A_ref, B_ref)` 是参考日期当天的同日基线。

### 7.2 残差取值

| 选项 | 显示 | 色阶 |
| --- | --- | --- |
| **绝对值（默认）** | `|残差|`，取值 0 → 1 | 顺序色阶（深色 → 亮黄） |
| 带符号 | 原始残差，取值 −1 → +1 | 发散色阶：蓝（残差减小）→ 近白（≈0）→ 红（残差增大） |

无论选哪种取值，**阈值、高亮和超阈值统计始终作用于 `|残差|`**，界面上有明确标注。

### 7.3 默认值规则

每次**进入**「跨日跨通道」组合（包括首次进入）时，都会重置为「正向 + 绝对值」。在同一组合内切换瓦片、通道或帧时，保留你当前选的方向与取值。

## 8. 热力图色阶分层

三个控件对**全部组合类型**都生效，用于把连续色阶改成按档离散着色，让相邻数值区间更容易分辨。

### 8.1 色阶模式

| 模式 | 非负量色域 | 带符号残差色域 | 说明 |
| --- | --- | --- | --- |
| 固定分段 | `[0, 1]` | `[-1, 1]` | 始终覆盖理论全量程；不同样本之间颜色含义一致，便于横向比较 |
| **动态分段（默认）** | `[0, x]` | `[-x, x]` | 把当前数据的实际范围拉伸到整条色带；`x` 就是下方阈值滑块的最大值 |

- 固定分段：适合对比多个瓦片、多个日期的结果，颜色含义不随数据变化。
- 动态分段：适合观察同一次比较内部的细节，小范围差异也能显出颜色层次。
- 动态模式的上界 `x` 与阈值量程完全一致，所以「滑块能取到的最大值」就是「色带的最右端」。

### 8.2 档数

整数输入，范围 **2–64**，默认 **12**。

- 档数越多，颜色分层越细，越接近连续渐变。
- 档数越少，色块越宽，越容易一眼区分区间，但细节丢失更多。
- 每档的颜色取色带在该档中点处的颜色，同一档内所有像素颜色相同。
- 色阶为偶数档时，带符号残差的 0 值正好落在档边界上（两档分别位于中性白两侧）。

### 8.3 档间边界线

开关，默认**开启**。

- 开启时，在相邻档位交界处绘制细线，线条颜色根据底色亮度自动取黑或白并半透明混合，因此在深色档和浅色档上都可辨认。
- 边界线沿数据形状绘制（等值线），不是规则的网格线。
- 关闭后只剩颜色跳变，不画线。
- 「二值掩膜」显示模式不渲染分档底色，因此该模式下不绘制边界线（否则等值线会盖住红色掩膜）；开关状态会保留，切回「半透明红色叠加」或「灰底彩色高亮」后继续生效。

### 8.4 色标

左栏下方的色条与热力图使用同一套色域、档数和边界线设置，显示为离散色带，并在文字中标明：

- 当前模式（固定分段 / 动态分段）；
- 档数；
- 色域两端数值（非负量为 `0 → x`，带符号为 `−x → 0 → +x`）。

### 8.5 重要：色阶不影响数值

分层只是显示方式。阈值比较、超阈值像素统计和量程计算都使用未分档的连续数值，调整档数或开关边界线**不会改变任何统计数字**。

---

## 9. 阈值

阈值决定哪些像素被算作「超过阈值」并高亮。

### 9.1 量程

阈值滑块的量程不是固定的 `[0, 1]`，而是随当前可视化量自适应：

- 记当前量的最大值为 `m`，则步长约为 `m/100`，上界 `x` 是严格大于 `m` 且对齐到步长的最小值。
- 实际可选范围是左开右闭的 `(0, x]`：**阈值永远取不到 0**，最小值是一个步长。
- 当滑到最右端 `x` 时，高亮像素数一定为 0。
- 左栏会显示「当前量程 (0, x]、步长、最大值」，以及一行「当前阈值 = …」。

### 9.2 默认阈值

- 量程上界 `x ≥ 0.30` 时，默认取 `0.30`；
- `x < 0.30` 时，默认取 `x / 2`，并限制在一个步长以上。

切换组合类型、数据根、瓦片、视图/通道、帧或掩膜开关时会重新计算量程和默认阈值。

### 9.3 滑块与数值框

滑块和右侧数值框双向同步：拖动滑块会更新数值框，在数值框输入会同步滑块。超出允许范围的输入会被自动夹到 `(0, x]` 内并对齐到步长。

阈值作用的量：

| 组合类型 | 阈值作用对象 |
| --- | --- |
| 同通道跨日 | 距离 `d = (1 − cos) / 2` |
| 同日跨通道 | 通道差异基线 `base` |
| 跨日跨通道 | `|残差|`（带符号模式下也是绝对值） |

---

## 10. 高亮显示模式

三种模式改变「超阈值像素怎么画」，不改变数值。

| 模式 | 底图 | 超阈值像素 | 适用场景 |
| --- | --- | --- | --- |
| **半透明红色叠加（默认）** | 完整分档色阶 | 叠加半透明红色 | 同时看整体分布和超阈值区域 |
| 二值掩膜 | 深色背景 | 纯红 | 只看「哪里超阈值」，忽略数值大小 |
| 灰底彩色高亮 | 灰度（按数值明暗） | 保留分档彩色 | 让超阈值区域在灰度底图上突出 |

掩膜开关开启时，掩膜外像素在三种模式下都显示为中性灰。

## 11. common_mask 开关

「应用 common_mask」控制是否使用该传感器自带的有效像素掩膜。

- **关闭（默认）**：全部 16384 个像素都参与着色和统计。
- **开启**：只有掩膜内像素参与着色与统计，掩膜外像素显示中性灰；统计分母变为掩膜像素数。

同一个瓦片下，不同传感器各有独立掩膜（像素数也可能不同），程序按视图名前缀自动选择对应传感器的掩膜。

切换开关会重算阈值量程（因为参与统计的像素集合变了），热力图、统计和色条同步更新。

## 15. DW 标签对比页

地址 `/dw`。页面用于检查带 Dynamic World（DW）标签的数据包：两期标签对不对得上、变化过渡落在哪里、整瓦片的嵌入距离分布如何。

### 15.1 数据根目录

- 输入框默认是 `--dw-data-root`；未指定时自动查找仓库同级的 `AEF_DW_change_data_20261031`。
- 只接受确实含 DW 标签的数据包；不含标签时状态区显示「该数据包不含 DW 标签」，**当前已加载的数据保持不变**。
- 切换成功后重扫瓦片、标签、过渡掩膜、manifest 与预览图；原瓦片不存在时回退到第一个含 DW 标签的瓦片。
- 数据根选择按页独立，不与 AEF 页共享，也不写入配置文件。

### 15.2 瓦片与传感器

- **瓦片**：只列出 `land_cover/dynamic_world.npz` 存在的瓦片，标签显示 `tile_id` / `region_id` / `split`。
- **传感器 / 视图**：只列出能比较两帧的视图（DW 包为 `sentinel2`、`sentinel1`），默认优先 `sentinel2`。
- 每次只比较**同一传感器**内前期第 0 帧与后期最后一帧，不提供 S2 ↔ S1 跨传感器对比。

### 15.3 标签图

- 前后两期各一张 128×128 标签图，按数据包 `dynamic_world_legend.json` 的官方色值逐像素渲染；代码 0–8 为类别，255 或 `valid_mask` 为假的像素显示为中性灰。
- 使用最近邻放大，类别边界保持锐利，不做平滑插值。
- 图上叠加：
  - **青色轮廓** = `candidate_mask`（DW 前后类别变化的像素）；
  - **品红矩形** = `bbox_yxyx` 包围框，`[y0, x0, y1, x1]` 且末端不含。
- 左侧图例列出 9 个类别的代码、名称与色块，以及 255（无效）、两种叠加线的含义。

### 15.4 元信息与 pmax

页面显示 `tile_id`、`region_id`、`split`、`before_class → after_class`、DW 标签日期、所选视图的**嵌入日期**（两者可能不同，S1 最多相差 5 天）、`candidate_mask` 像素数、manifest 的 `core_pixels`、`bbox_yxyx`、`before_label`/`after_label`。

置信度分两组，标签不同：
- `manifest 记录值`：数据包 `tile_manifest.json` 里的 `before_mean_confidence` / `after_mean_confidence`。
- `整瓦片`：页面用 `pmax` 在整瓦片有效像素上重新求的均值。

两者都是**模型概率**，不是准确率或精度。页面常驻声明：DW 标签是模型分类结果，不是人工核实真值；本页不提供准确率、精度或真值一致性评估。

### 15.5 整瓦片统计

- 距离：`d = (1 − cos) / 2`，与 AEF 页同一实现。
- 有效像素：嵌入可用（有限、非零范数）、掩膜为真、且两期 DW 标签都有效。
- **统计范围只有一个：整瓦片的全部有效像素**，不按 `candidate_mask` 或 `bbox_yxyx` 做任何筛选或分组。
- 显示：有效像素数 / 总像素、阈值、超阈值像素数与比例、`d` 均值、中位数、p90、p95、最大值、掩膜来源。
- 切换瓦片、传感器或阈值后，热力图与统计立即更新。

### 15.6 热力图显示自定义

DW 页提供与 AEF 页相同的一组显示控件（默认值与 AEF 页一致），只影响热力图与色条：

| 控件 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 高亮显示模式 | 半透明红色叠加 / 二值掩膜 / 灰底彩色高亮 | 半透明红色叠加 | 二值掩膜模式不绘制档间边界线 |
| 色阶模式 | 固定分段 / 动态分段 | 动态分段 | 固定分段量程 `[0, 1]`；动态分段量程 `[0, x]`，`x` 为当前阈值量程上界 |
| 档数 | 整数，2–64 | 12 | 越界输入夹取到边界并回写；清空或输入非数字时保持上一值 |
| 档间边界线 | 开关 | 开启 | 关闭后热力图与色条都不画档间等值线 |

- 色阶**只影响显示**：距离数值、阈值、阈值量程、超阈值统计与统计分组都不变。
- 控件只作用于热力图与色条；标签图始终按官方配色全彩显示，`candidate_mask` 轮廓与 bbox 矩形始终显示。
- 色标会同步标注当前色阶模式、档数与边界线状态，例如「色标（动态分段 · 12 档 · 档间边界线 = 开）：0.000 → 0.376」。

### 15.7 热力图与预览图

- 热力图：128×128 分档着色（按上一节的当前设置），叠加上阈值高亮、青色 `candidate_mask` 轮廓与品红 bbox。
- 标题分别标注所选传感器与**嵌入日期**，不混用 DW 标签日期。
- 右侧显示 `preview.png` 与 `review.png`，按原始宽高比完整显示；文件缺失时给出可读提示。
- 全部图像保持**原生朝向**，不旋转。

### 15.8 本页不做的事

- 不做跨传感器比较。
- 不做核心区 / 核心区外分组统计。
- 不评估标签正确性，不给准确率、精度、召回率或混淆矩阵。

## 16. 常见问题

**Q：输入路径后提示「既不是数据包根……也不是瓦片目录」？**
A：确认该目录下要么有 `tiles/` 子目录且里面直接是瓦片文件夹，要么该目录本身就是这样的瓦片容器（名称不限）。只含 `gallery/` 或空的瓦片目录都不算有效。

**Q：切换数据根后瓦片变了，原来的瓦片找不到了？**
A：这是预期行为：原瓦片在新数据包中不存在时，会自动选中新数据包的第一个瓦片。

**Q：某类组合类型下视图列表为空？**
A：跨日类组合要求帧数 ≥ 2。只有单期观测的 Landsat 瓦片（如 C05/C06/C10/C12/C17/C18/C19/C21）在跨日类型下不会列出 Landsat 视图；改用同日跨通道仍可查看。

**Q：阈值滑块怎么拖都拖不到 0？**
A：量程设计为左开 `(0, x]`，最小值是一个步长，滑块不允许取 0。

**Q：调整档数或边界线后统计数字变了？**
A：不应该变。分层只影响显示；若发现数值变化请报告为缺陷。

**Q：热力图和图像为什么是竖着的？**
A：两者都在内存中顺时针旋转了 90° 显示，以便两帧画面并排同屏；这只是一次统一的显示变换，不改变任何数值。

**Q：能看到准确率或置信度吗？**
A：不能，也没有提供。数据不含变化参考标注，所有结果仅作探索性对照。DW 页展示的 pmax 是模型对该类别给出的概率，不是准确率或精度。

**Q：DW 页的档数/色阶模式和 AEF 页一样吗？**
A：一样。两页共用同一套渲染函数与常量（档数范围 2–64、默认 12、越界夹取回写），默认设定也相同：动态分段、12 档、档间边界线开启、半透明红色叠加。区别只在 DW 页固定分段的量程恒为 `[0, 1]`，因为本页只显示非负的距离 `d`。

**Q：DW 页改了色阶模式/档数后，统计数字为什么没变？**
A：这是设计如此。色阶只决定显示颜色，不改变距离、阈值、量程或任何统计。

**Q：DW 页为什么没有「变化核心区内 / 核心区外」两组数字？**
A：本版统计口径就是**整个瓦片**，只给一组数。`candidate_mask` 与 `bbox_yxyx` 只作为标签图和热力图上的空间叠加，用于看位置，不参与任何统计筛选。

**Q：DW 页的 S2 和 S1 能直接比较吗？**
A：不能，本页没有跨传感器比较入口。页面只做同一传感器内的前后两期比较；两传感器的日期最多相差 5 天，跨模态差异不能被解释为变化。

**Q：DW 页的标签图为什么没有旋转？**
A：DW 页的标签图、热力图与 `preview.png` 都保持数据原生朝向，这样能与预览图的面板逐像素对齐。AEF 页仍保留顺时针 90° 的约定。

**Q：DW 页显示「该数据包不含 DW 标签」？**
A：说明所填数据根下没有任何 `tiles/*/land_cover/dynamic_world.npz`。旧包（`data/spectral`）没有 DW 标签，请留在 AEF 页查看，或用 `--dw-data-root` 指向 DW 数据包。

## 17. 计算口径速查

| 量 | 公式 |
| --- | --- |
| 像素距离 | `d = (1 − cos) / 2`，取值 `[0, 1]` |
| 同日基线 | `base = d(A_ref, B_ref)` |
| 正向残差 | `fwd = d(A_ref, B_other) − base` |
| 反向残差 | `rev = d(B_ref, A_other) − base` |
| 对称化残差 | `sym = (fwd + rev) / 2` |

- 残差取值截断在 `[−1, 1]`。
- 距离计算前对每个像素向量做 L2 归一化；零范数或非有限值的像素按无效处理。
- 本实现的 `d` 与数据包自带的 `C0_*` / `C1_*` / `same_modality_*` 数值相差严格 2 倍（后者使用 `1 − cos`），界面与统计不混用这些数值。
- DW 页的距离仍是同一个 `d = (1 − cos) / 2`，只用同一传感器内前后两期嵌入，统计范围为整瓦片全部有效像素。
