# 变化检测 WebUI 规格

## 目的

本 capability 提供一个本地 NiceGUI 平台，包含两个页面：

1. **AEF 无监督变化检测**：按 AlphaEarth Foundations (AEF) 论文补充材料 S4.1 的无监督变化检测流程，对同一瓦片像素嵌入做逐像素比较，输出可交互的变化程度热力图，并与数据包中的原始图像并排呈现。支持三种组合类型：
   - **同通道跨日（同模态对照）**：同一瓦片、同一传感器、同一视图的两帧比较；
   - **同日跨通道（跨模态基线）**：同一瓦片、同一传感器、同一日期、两个不同视图，输出通道差异基线，**不是变化检测结果**；
   - **跨日跨通道（跨模态变化，探索性）**：同一瓦片、同一传感器、两个不同视图，各自取不同日期，输出扣除同日基线后的残差。
2. **AEF 变化检测与 DW 标签对比**：对带 Dynamic World（DW）标签的数据包，展示两期 DW 标签与官方配色、`candidate_mask` 与 bbox 叠加、manifest 元信息，并给出整瓦片的嵌入距离统计。统计口径为整个瓦片，不划分「核心区 / 核心区外」。

平台采用「入口脚本 + 页面模块」结构；根路径 `/` 仍直接呈现 AEF 页。

数据集不提供人工核实的变化真值；DW 标签本身是模型分类。所有结果只能作为探索性对照，界面不得出现准确率、精度或真值类结论。

## 平台结构

### 路由与导航

| 路径 | 页面 |
| --- | --- |
| `/` | AEF 无监督变化检测页（与 `/aef` 内容一致） |
| `/aef` | AEF 无监督变化检测页 |
| `/dw` | AEF 变化检测与 DW 标签对比页 |

- 每个页面顶部常驻平台标题栏，包含两个页面入口（「AEF 无监督变化检测」「AEF 变化检测与 DW 标签对比」）。
- 当前页面入口具有可见的选中样式（例如高亮底色/加粗），另一入口为普通样式。
- 点击入口进行整页切换，不要求刷新浏览器或重启进程；切换后目标页按默认状态构建。
- 页面各自独立构建：数据根选择、控件状态与缓存不跨页面共享。
- 页面标题（浏览器标签）分别设为「AEF 无监督变化检测」与「AEF 变化检测与 DW 标签对比」。

### 模块结构

- 入口：`app/change_detection_webui.py`，负责命令行参数解析、页面注册与服务启动。
- 数据访问：`app/webui/dataset.py`，包含路径解析与 `Dataset`（含 DW 兼容回退）。
- 计算与渲染：`app/webui/render.py`，包含距离、色阶、阈值量程、统计与 PNG 编码。
- 页面外壳：`app/webui/layout.py`，提供标题栏、导航、全局样式与三栏容器。
- AEF 页：`app/webui/aef_page.py`；DW 页：`app/webui/dw_page.py`；DW 读取：`app/webui/dw_data.py`。
- 模块拆分不改变任何用户可见行为；入口脚本保持 `--host`、`--port`、`--data-root`、`--show` 语义，并新增 `--dw-data-root`。

## 输入数据契约

### 嵌入

- 路径：`<tile container>/<tile>/embeddings/<view>.npy`
- 形状：`(frames, 128, 128, 64)`，`float32`，每像素向量已为单位长度。
- 帧元数据：同目录 `<view>_index.json`，`frames[i]` 提供 `date_utc`、`timestamp_ms`、`parent_raw_index`、`sensor_id` 等字段。

### 视图与传感器（旧包）

- view 名形如 `<sensor>_<bandset>`，传感器前缀为 `sentinel2` 或 `landsat`。
- Sentinel-2 视图：`full`、`visible`、`nir`、`swir`、`reflective_ir`。
- Landsat 视图：`full`、`visible`、`nir`、`swir`、`thermal`。
- `full` 是唯一分布内视图；其余单通道或组合通道视图均为波段消融的**分布外诊断**，界面必须逐通道标注。
- 同一瓦片同一传感器下，各 view 的 `date_utc` 与 `parent_raw_index` 完全一致（同一成像），因此同日期、同帧序号的跨 view 取帧对应同一次观测。
- 数据规模：Sentinel-2 共 33 个瓦片（32 个两期 + V01 三期，共 67 个 epoch）；Landsat 共 20 个瓦片（12 个两期 + 8 个仅一期，共 32 个 epoch）。8 个单期 Landsat 瓦片为 C05/C06/C10/C12/C17/C18/C19/C21，其 Landsat 视图只有 1 帧。
- 跨传感器比较不在本 capability 内；跨通道的 A、B 通道必须属于同一传感器。

### DW 数据包差异

DW 数据包（参考 `AEF_DW_change_data_20261031`）与旧包的差异必须由读取层兼容：

| 项目 | 旧包 | DW 包 |
| --- | --- | --- |
| 视图命名 | `<sensor>_<bandset>` | `sentinel2`、`sentinel1`（无波段组） |
| 每视图帧数 | 1–3 | 2（前、后两期） |
| `distance_maps/` | 存在，含按传感器的 `common_mask` | 不存在 |
| `gallery/index.json` | 存在 | 不存在；瓦片目录下有 `preview.png`、`review.png` |
| `tile_manifest.json` 字段 | `id`、`category`、`parent`、`split`、`views` | `tile_id`、`region_id`、`path`、`split`、`before_date`、`after_date`、`before_label`、`after_label`、`before_class`、`after_class`、`core_pixels`、`bbox_yxyx`、`before_mean_confidence`、`after_mean_confidence` |
| DW 标签 | 无 | `<tile>/land_cover/dynamic_world.npz` + 包根 `dynamic_world_legend.json` |
| 标签过渡掩膜 | 无 | `<tile>/masks/label_transition.npz` |

### 兼容回退

- **视图名无波段组**：`<sensor>` 前缀仍用于传感器识别；界面把这类视图标注为“单视图（无波段组）”，不得标注“分布内/分布外”（后者只适用于旧包的 `full` 与波段消融视图）。
- **无 `distance_maps`**：按以下顺序取掩膜，界面必须注明实际来源：
  1. `distance_maps/<sensor>_*.npz` 的 `common_mask`；
  2. `land_cover/dynamic_world.npz` 的 `valid_mask[0] & valid_mask[1]`（需至少 2 帧）；
  3. `observations/<sensor>.npz` 的 `valid_mask` 各帧取与；
  4. 全 True。
- 若 `distance_maps/` 目录存在但缺少该传感器掩膜，仍按既有契约为错误，不得静默回退（保持归档结论 A6）。
- **无 `gallery/index.json`**：AEF 页的缺图提示需要说明该包无 gallery 索引；DW 页的图像区回退显示该瓦片的 `preview.png` 与 `review.png`。
- **manifest 字段差异**：瓦片标签按 `category` → `region_id` → `tile_id` 回退；坐标按 `parent` → `region_id` 回退；`split` 缺失时显示“未标注”。

### 有效像素掩膜

- 旧包：`distance_maps/<sensor>_*.npz` 中的 `common_mask`，`bool`，形状 `(128, 128)`。
- `<sensor>` 取 view 名的前缀（`sentinel2` 或 `landsat`）。同一瓦片下不同传感器各有独立掩膜，必须按传感器选取，不得取目录中第一个文件，也不得回退到其他传感器的掩膜。
- 同一瓦片同一传感器内，所有 view 共用同一 `common_mask`（53 组已验证）；因此跨通道可直接复用，但不得跨传感器复用。
- 掩膜的使用受 AEF 页开关控制：开关关闭（默认）时不应用掩膜，全部像素参与着色与统计；开关开启时，掩膜为假的位置不参与任何统计且热力图中以中性灰显示。
- 掩膜外的嵌入向量本身可能包含有效数值（实测 C01 的 413 个掩膜外像素范数为 1、无 NaN、两帧互不相同），因此关闭掩膜后必须按正常距离着色，不得因为“曾被掩膜排除”而输出灰块或异常颜色。
- DW 页始终只统计“嵌入可用且掩膜为真”的像素，并显示掩膜来源与有效像素数。

### 图像（旧包 gallery）

- `gallery/index.json` 为数组，元素含 `id`、`source`、`date`、`image`；`image` 以 `spectral/` 为前缀，相对旧包根解析。
- 以 `(id=tile, source=encoder_source, date=date_utc)` 为键精确匹配该帧的 PNG，共 98 条唯一键；每个瓦片-传感器-日期只有一张整幅图。
- 唯一缺图为 V01/sentinel2/2024-09-01：索引无该记录。
- gallery 文件按 `{tile}_{source}_{帧序号}.png` 命名，日期到文件名的映射只能经 index 完成。缺失提示必须说明该命名模式与当前瓦片已有文件，不得拼接日期形状的伪文件名。
- 缺失提示区分两种情况：索引无该日期记录；索引有记录但文件不存在（后者给出记录中的路径）。
- gallery PNG 为预渲染多面板图：Sentinel-2 为 RGB/NIR/SWIR 三面板，Landsat 为 RGB/NIR/SWIR/Thermal 四面板，每面板 256×256，纵向位于第 48–303 行；图上方有标题、下方有说明。本 capability 按原样完整显示，不裁剪。

### 组合规模

按全部 5 个视图（含 `full`）计：

- 同日跨通道：990 组（Sentinel-2 670 / Landsat 320）。
- 跨日同通道：235 组（Sentinel-2 175 / Landsat 60）。
- 跨日跨通道：470 组（Sentinel-2 350 / Landsat 120）。

若只计四个严格单通道（排除 `full`），对应为 594（402/192）、188（140/48）、282（210/72）；跨日类共 45 个多期瓦片-传感器组。

## 计算

### 距离

对两个帧 `i`、`j` 的嵌入张量 `X`、`Y`，逐像素计算：

```
cos(p) = <X[p], Y[p]> / (||X[p]|| * ||Y[p]||)
d(p)   = (1 - cos(p)) / 2
```

实现要求：

- 计算前对每个像素向量做 L2 归一化；零范数向量按无效处理。
- `d` 的取值截断在 `[0, 1]`。
- 该定义与论文公式 (8) 一致，`0` 表示两帧完全相同，`1` 表示方向相反。
- 必须独立于数据包自带的 `distance_maps` 数值实现；后者仅用于掩膜。
- 数据集自带的 `C0_epoch_*`、`C1_*`、`same_modality_*` 使用 `1 - cos`，是本实现 `d` 的 2 倍；界面与统计不得混入这些数值。严格 2 倍关系可用于验收比对，不得用于展示。

### 同通道跨日

同一 view 的两帧 `i < j`，输出 `d(X[i], Y[j])`。

### 同日跨通道

同一瓦片、同一传感器、两个不同视图 A、B，取同一帧序号 `t`（同一日期）：

```
base(p) = d(A[t], B[t])
```

输出 `base` 作为基线图。基线高值表示两通道之间的固有差异，不是变化。该类型必须保留阈值、高亮与超阈值统计（阈值作用于基线值），并在界面明示“高值 = 通道差异基线，不代表变化”。

### 跨日跨通道

同一瓦片、同一传感器、两个不同视图 A、B。A 的所选帧序号为 `ref`，其日期为参考日期；B 的所选帧序号为 `other`，且日期必须不同（`other != ref`）。

```
base(p) = d(A[ref], B[ref])                    # 参考日期的同日基线
fwd(p)  = d(A[ref], B[other]) - base(p)        # 正向残差
rev(p)  = d(B[ref], A[other]) - base(p)        # 反向残差
sym(p)  = (fwd(p) + rev(p)) / 2                # 对称化残差
```

- `base`、`fwd`、`rev`、`sym` 取值截断在 `[-1, 1]`。
- `sym` 必须按上式逐像素计算，不得用两个方向的均值距离再减去基线以外的其他口径。
- 三个残差均带符号：负值表示该跨日期距离低于参考日期的同日基线（通道差异减弱），正值表示高于基线（通道差异增强）。

### 帧选择

- **同通道跨日**：`frames == 2` 固定使用第 0 帧与第 1 帧，不提供帧对选择；`frames > 2` 提供全部 `i < j` 组合，默认首帧与末帧；`frames < 2` 的视图不进入该类型的选择器。
- **同日跨通道**：提供单一共享帧选择器，列出该传感器全部帧（两通道同日期，选择器同时决定两通道帧）；`frames > 2` 时可选任意帧；`frames == 1` 时选择器隐藏或仅一个选项。
- **跨日跨通道**：提供 A、B 两个帧选择器；A 默认首帧（0），B 默认末帧（`n-1`）；B 的可选日期不得等于 A 的当前日期，A 改变导致冲突时 B 自动改为第一个不同日期的帧。

### 视图可用性过滤

- **同通道跨日**：只列 `frames >= 2` 的视图（现有行为）；单帧视图在元信息中列出并说明排除原因。
- **同日跨通道**：列该瓦片全部视图，要求 A、B 同传感器且不相同；单帧视图可参与（因为不需要两期）。
- **跨日跨通道**：只列 `frames >= 2` 的视图；单期 Landsat 瓦片的 Landsat 视图不得出现在 A 或 B 的可选项中，因此不会产生不可算组合。
- 跨通道类型中，A 选择器列出全部可用视图；B 选择器只列与 A 同传感器且不同于 A 的视图。切换 A 的传感器时，B 自动重置为该传感器下第一个不同于 A 的视图。
- 默认：A = `sentinel2_visible`，B = `sentinel2_nir`；若不可用，回退到该瓦片第一个可用传感器的前两个不同视图。跨日跨通道的 A 帧默认 0、B 帧默认末帧。

### 阈值量程

阈值控件的量程随当前被可视化的非负量自适应，不再固定为 `[0, 1]`。

记当前被可视化的量（非负）为 `q`，参与统计的像素集合为 `S`（由 `common_mask` 开关决定），`m = max(q[p] for p in S)`。量程为左开右闭的 `(0, x]`：左端 `0` 不提供，最小可选值为一个步长。

- 同通道跨日：`q = d`。
- 同日跨通道：`q = base`。
- 跨日跨通道：`q = |r|`，`r` 为当前选中的残差（fwd / rev / sym）。带符号视图下阈值仍然作用于 `|r|`，不是作用于带符号值本身。
- DW 页：`q = d`（当前传感器两期嵌入距离），`S` 为整瓦片有效像素。

量程规则：

1. 步长 `step` 取约 `m/100`，保留到合适精度（不小于 `0.0001`），使量程小时仍有约 100 个档位。
2. 上界 `x` 取严格大于 `m` 并对齐到 `step` 的最小值，即 `x = ceil(m / step + ε) * step`，并截断到 `1.0`。
   - 必须保证 `count(q > x) == 0`，即滑块到达上界时没有任何高亮像素。
   - 量程左端为排除值：滑块与数值框的最小值均为 `step`，因此阈值永远取不到 `0`，实际可选范围为 `(0, x]`。
   - 若 `m == 0`（所有像素量为 0），令 `x = step`，此时最小值与最大值同为 `step`，任何阈值下高亮数均为 0。
3. 默认阈值：
   - 当 `x >= 0.30` 时取 `0.30`；
   - 当 `x < 0.30` 时取 `x / 2`；
   - 均对齐到 `step` 并限制在 `[step, x]`（左端不可为 0）。
4. 切换组合类型、瓦片、视图/通道、帧（对）、`common_mask` 开关或 DW 页的瓦片/传感器时，重新计算 `step`、`x` 与默认阈值。

### 统计

在参与统计的像素集合内计算。该集合由 `common_mask` 开关决定（DW 页固定为整瓦片有效像素）。

通用统计（AEF 页三类组合均保留）：

- 参与统计的像素总数；
- 高于阈值的像素数与占比 `count / total`；
- 当前可视化量的中位数、p95、最大值。

其中“高于阈值”统一按 `q > threshold` 判定：非负量视图 `q` 即其本身；跨日跨通道带符号视图 `q = |r|`。中位数/p95/最大值按当前可视化量计算：带符号视图下分别为 `median(r)`、`percentile(r, 95)`、`max(r)`，并额外显示 `min(r)`；绝对值视图与另两类组合按非负量计算。

跨日跨通道额外显示（无论当前选中哪个残差视图，均同时显示）：

- 同日基线均值 `mean(base)`；
- 正向残差均值 `mean(fwd)`；
- 反向残差均值 `mean(rev)`；
- 双向均值之差 `mean(fwd) - mean(rev)`（带符号显示）；
- 对称化残差均值 `mean(sym)`。

统计标签必须说明当前可视化量、阈值作用对象（`q` 或 `|r|`）与分母来自哪种掩膜状态，避免把不同口径的数字混淆。

DW 页的整瓦片统计见「AEF 变化检测与 DW 标签对比页」。

## AEF 无监督变化检测页

### 控件

1. **组合类型选择器**：三个选项，见「组合类型」，默认 `same_channel`（保持现有默认体验）。
2. **瓦片选择器**：列出当前数据根下全部瓦片，显示类别/区域与 split 作为辅助信息；默认优先 `C01`，否则第一个瓦片。
3. **通道选择**：
   - 同通道跨日：单一视图选择器，列出可做两帧比较的视图，默认 `sentinel2_full`；被排除的单帧视图在元信息中说明。
   - 同日跨通道 / 跨日跨通道：A、B 两个视图选择器，按「视图可用性过滤」约束；切换 A 后 B 的选项随之更新。
4. **帧选择**：
   - 同通道跨日：帧对选择器，仅当 `frames > 2` 时出现。
   - 同日跨通道：单一帧选择器。
   - 跨日跨通道：A 帧、B 帧两个选择器。
5. **残差视图选择器**（仅跨日跨通道）：
   - 残差方向：正向 / 反向 / 对称化；进入该组合类型时默认「正向」。
   - 残差取值：带符号 / 绝对值；进入该组合类型时默认「绝对值」。
   - 离开后再次进入仍回到该默认；用户手动改动后，在该组合类型内切换瓦片/通道/帧保持其选择。
   - 另提供当前选中的单向/对称化说明文字与公式。
6. **阈值滑块**：量程 `(0, x]` 由当前可视化量自适应计算（见「阈值量程」），最小值为 `step`、最大值为 `x`，步长自适应；同时提供数值输入框，其最小值同为 `step`，二者双向同步，数值精度随量程调整。滑块与数值框均需实时显示当前阈值，并显示当前量程上界 `x`。带符号视图必须写明“阈值与高亮作用于 |残差|”。
7. **显示模式选择器**：三种模式，见「显示模式」。默认「半透明红色叠加」。
8. **common_mask 开关**：默认关闭（全部像素参与着色与统计）。开启时应用掩膜，掩膜外像素显示中性灰且不计入统计；关闭时全部像素参与着色与统计。切换后无需刷新页面即可看到热力图与统计变化。
9. **热力图色阶分层**：
   - 色阶模式：固定分段 / 动态分段，默认动态分段；
   - 档数：整数输入，默认 12，范围 2–64；
   - 档间边界线：开关，默认开启；
   - 固定分段使用全量程（非负 `[0, 1]`、带符号 `[-1, 1]`）；动态分段使用与阈值量程一致的上界 `x`（非负 `[0, x]`、带符号 `[-x, x]`）；
   - 色条同步显示离散档位与量程端点；
   - 色阶只影响显示，不改变阈值、超阈值统计与量程；
   - 二值掩膜模式不绘制档间边界线，其余两种模式按开关生效。
10. **瓦片坐标**：瓦片选择器下方显示当前瓦片中心经纬度，来源见「元数据展示」。
11. **数据根目录**：输入框 + 「应用」按钮，初始值等于当前生效的数据根（默认 `data/spectral` 的绝对路径；瓦片容器名不是 `tiles` 时显示该容器路径，以保证原样再次应用得到同一结果）；输入框下给出可填形态说明与当前数据根状态。

### 组合类型语义

| 值 | 界面标签 | 语义说明 |
| --- | --- | --- |
| `same_channel` | 同通道跨日（同模态对照） | 同一视图不同日期；高值 = 变化程度 |
| `same_day` | 同日跨通道（跨模态基线） | 同一日期两个通道；高值 = 通道差异基线，不代表变化 |
| `cross_day` | 跨日跨通道（跨模态变化） | 两个通道不同日期；显示扣除同日基线后的残差，探索性对照 |

当前结果所属类型必须始终显示在结果区，不能只靠选择器控件隐含表达。

### 结果语义提示

结果区必须常驻显示当前组合类型及其语义提示：

- 同通道跨日：“同模态对照：同一视图不同日期，高值表示变化程度。”
- 同日跨通道：“跨模态基线：同一日期的通道差异，高值不代表变化。”
- 跨日跨通道：“跨模态变化（探索性）：残差 = 跨日期距离 − 同日基线；数据不含变化参考标注，仅作探索性对照。”

### 热力图

以 `128 x 128` 场为数据源，按当前色阶模式分档着色并显示色条。

- 非负量（同通道跨日距离、同日跨通道基线、跨日跨通道绝对值视图）：顺序色阶，固定分段 `[0, 1]`，动态分段 `[0, x]`。
- 跨日跨通道带符号视图：发散色阶，固定分段 `[-1, 1]`，动态分段 `[-x, x]`，`0` 为中性色；负端为蓝色、正端为红色。
- 色条标注当前模式、档数、量程端点；带符号视图注明“负 = 残差减小，正 = 残差增大；阈值与高亮作用于 |残差|”。
- 掩膜开关开启时，掩膜外的像素显示为中性灰，不参与色阶；关闭时全部像素按当前量着色。
- 热力图与显示模式无关的底图行为保持一致，切换模式不改变数值。
- 热力图上叠加超阈值区域时，阈值使用滑块当前值；色阶与阈值量程解耦（固定分段时）。
- **朝向**：热力图必须与右侧 gallery 图像处于同一朝向，即渲染完成后顺时针旋转 90° 再显示。旋转只改变显示朝向，不改变 128×128 的像素计数、统计数值或阈值量程。热力图标题必须标注“顺时针旋转 90°”。

### 显示模式

1. **半透明红色叠加**（默认）：在完整分档热力图上，对 `q > threshold` 的像素叠加半透明红色。带符号视图下 `q = |r|`，底图仍按带符号发散色阶着色。
2. **二值掩膜**：`q > threshold` 的像素显示为红色，其余有效像素显示为深色；掩膜外仍为中性灰。
3. **灰底彩色高亮**：`q > threshold` 的像素保留热力图配色，其余有效像素转为灰度。带符号视图下灰度按 `|r|` 计算。

### 图像区域

- **同通道跨日**：显示与所比较两帧对应的两张 gallery 整幅图，各自标注 `date_utc` 与来源。
- **同日跨通道**：两通道同日期，gallery 只有一张图；只显示一次，标注“同一观测，两通道”并给出 A、B 通道名与日期，不得重复渲染成两张。
- **跨日跨通道**：显示该传感器两个日期对应的整幅图（A 参考日期与 B 目标日期），各自标注日期与通道名。
- **图像朝向**：gallery 图按原样从磁盘读取后，在内存中顺时针旋转 90° 再显示；`data/` 下文件不得被修改。旋转后单张整幅图由横向 `768×340` 变为纵向 `340×768`。旋转结果与热力图保持同一朝向。
- **布局**：图像区位于热力图右侧，两张整幅图**左右并排**（同高度、同一顶边），使两帧画面可同时看到；不使用原先的上下堆叠。图像按宽高比缩放，限高为视口高度的 72%，不得拉伸变形。页面上方标注“gallery 原始图像（顺时针旋转 90°，两帧并排）”。
- **同日跨通道**：只有一张图，占左侧一列；右侧列隐藏，不得显示空白占位以外的重复图。
- 图像缺失或匹配失败时，按「图像」契约显示具体缺失的日期、gallery 命名模式与该瓦片现有文件；索引有记录但文件不存在时还要给出记录路径。V01 的 2024-09-01 无索引记录，必须显示“索引无记录”分支。缺图提示需保留换行（多行文本），不得压成一行。若数据根没有 `gallery/index.json`，提示需说明该包无 gallery 索引。

### 元数据展示

在页面上显示：

- 当前瓦片的 `split`、类别（`category`，缺失时回退 `region_id`/`tile_id`）；
- 组合类型名称与语义提示；
- A、B 通道名（同通道跨日为一个视图）、各通道所属传感器、波段标识（无波段组时显示“无波段组”）；

界面不得出现准确率、置信度或真值类表述。

### 数据根切换

- 路径解析同时接受数据包根（含瓦片容器与 `gallery/`）与直接包含瓦片子目录的瓦片容器（名称不限）；同一数据根下存在多个候选容器时要求直接指定其中一个。
- 切换前必须完成预检（枚举瓦片、逐个读取 manifest、确认目标瓦片至少有一个嵌入视图）；切换生效后的界面重建若仍失败，必须回滚数据根、瓦片下拉、选择状态与阈值控件，并保留用户已调阈值。
- 非法路径不得破坏当前已加载的数据；错误信息说明原因。
- 切换后若原瓦片在新根不存在，自动回退到新根内第一个可用瓦片并完成一次完整刷新。
- 数据根选择不写配置文件、不跨页面共享。

### 布局与滚动

页面采用三栏横向布局：左侧控制与统计栏、中间热力图栏、右侧图像栏，位于平台标题栏下方。

- **整页不滚动**：页面总高度固定为视口高度，浏览器窗口层面不得出现纵向滚动条（`html`/`body` 高度占满且 `overflow: hidden`）。
- **各栏独立纵向滚动**：三栏各自拥有独立的纵向滚动容器，高度等于标题栏以下的可用高度。当某一栏内容超出时，只滚动该栏，热力图与图像保持原位。
- **滚动条样式**：独立滚动容器使用细滚动条（约 10px 宽、常驻可见），轨道与滑块颜色区分明显。
- 三栏宽度：左栏 360px 固定、热力图栏 540px 固定、图像栏占剩余宽度；允许横向滚动以适配窄窗口。
- 布局变化不影响任何数值、统计口径或图像内容。

## AEF 变化检测与 DW 标签对比页

### 数据来源

- 数据根解析与 AEF 页共用同一路径解析规则（数据包根或瓦片容器）。
- 瓦片列表只包含同时具备 `<tile>/land_cover/dynamic_world.npz` 的瓦片；其余瓦片在状态中说明被跳过。
- 标签数据：`dynamic_world.npz` 的
  - `label`：`uint8 (2, 128, 128)`，第 0 轴为前期、第 1 轴为后期；`0–8` 为类别代码，`255` 为无效；
  - `probabilities`：`float32 (2, 128, 128, 9)`；
  - `valid_mask`：`bool (2, 128, 128)`；
  - `pmax`：`float32 (2, 128, 128)`；
  - `timestamps_ms`：`int64 (2,)`；`class_names`：`(9,)`。
- 图例：数据包根 `dynamic_world_legend.json`，`classes[]` 提供 `code`、`name`、`color`（`#RRGGBB`），`nodata` 为无效值。页面必须按图例渲染，不得硬编码一套不同色值；图例文件缺失时回退到 `dynamic_world.npz` 的 `class_names`，并使用明确标注的占位配色。
- 标签过渡掩膜：`<tile>/masks/label_transition.npz` 的 `candidate_mask`（`bool (128, 128)`）、`bbox_yxyx`（`int64 (4,)`，`[y0, x0, y1, x1]`，末端不含）、`before_label`/`after_label`（标量 `uint8`）。
- 元信息：`<tile>/tile_manifest.json` 的 `tile_id`、`region_id`、`split`、`before_date`、`after_date`、`before_label`、`after_label`、`before_class`、`after_class`、`core_pixels`、`bbox_yxyx`、`before_mean_confidence`、`after_mean_confidence`。
- 预览图：`<tile>/preview.png`、`<tile>/review.png`。

### 标签配色与图例

- 标签图按像素渲染：类别代码 0–8 使用 `dynamic_world_legend.json` 的官方色值；`255` 与 `valid_mask` 为假的像素使用固定中性色（与 AEF 页掩膜灰同色系），并注明含义。
- 前后两期各一张标签图，标题分别标注日期（取自 `tile_manifest.json` 的 `before_date`/`after_date`，缺失时取 `dynamic_world_index.json` 的 `date_utc`）。
- 页面常驻图例：9 个类别各显示色块、代码与名称，另列“255 / 无效”色块。
- 标签图以最近邻放大显示，保持类别边界清晰，不做平滑插值。

### candidate_mask 叠加

- 在前后两期标签图上叠加 `candidate_mask` 的边界轮廓（宽度 1 像素，放大于显示分辨率后仍清晰可辨），并使用与标签色差异明显的固定颜色。
- 在同一图上叠加 `bbox_yxyx` 矩形（与参考包 `preview.png` 中的紫色矩形一致的语义），标题或图注说明“轮廓 = `candidate_mask`（DW 前后类别变化像素），矩形 = 其包围框”。
- 界面显示 `before_label` / `after_label` 的代码与类别名（例如 `7 bare → 6 built`）。
- 页面显示的 `core_pixels` 必须等于 `candidate_mask.sum()`；若与 manifest 的 `core_pixels` 不一致，界面同时显示两个值并说明来源，不得静默取其一。
- `candidate_mask` 只用于叠加显示与元信息，不参与嵌入距离的统计筛选。

### 元信息与 pmax 口径

- 显示 `tile_id`、`region_id`、`split`、`before_date → after_date`、`before_class → after_class`、`core_pixels`。
- 显示 `before_mean_confidence` 与 `after_mean_confidence`，标签必须写明“平均 pmax（模型概率）”，不得称为准确率、精度或置信度结论。
- 页面常驻声明：**DW 标签是 Dynamic World 模型分类结果，不是人工核实的地面真值；pmax 是模型对该类别给出的概率。本页不提供准确率、精度或真值一致性评估。**
- 若 manifest 的 `label_type` 字段存在，可原样展示其说明文本。

### 嵌入距离与整瓦片统计

- 传感器范围：只比较同一传感器内的前后两期。传感器选项来自该瓦片可用于两帧比较的视图（DW 包为 `sentinel2` 与 `sentinel1`；旧包按实际视图）。
- 对所选视图，前期取第 0 帧、后期取最后一帧（DW 包中均为 2 帧）；日期取自该视图 `*_index.json` 的 `frames[i].date_utc`。
- 距离：`d = (1 - cos) / 2`，与 AEF 页同一函数与同一数值口径，不得另写实现。
- 有效像素：嵌入可用（有限、非零范数）且掩膜为真；掩膜按「兼容回退」顺序取得，界面注明来源。
- 统计范围为整个瓦片的全部有效像素，不按 `candidate_mask` 或 `bbox_yxyx` 做任何筛选或分组。
- 显示：像素数、`mean(d)`、`median(d)`、`p90(d)`、`p95(d)`、`max(d)`、超阈值像素数与比例 `count(d > threshold) / count(有效像素)`。
- 阈值量程按「阈值量程」规则由该有效像素集合计算；阈值作用于 `d`，滑块与数值框双向同步。
- 切换瓦片、传感器或阈值后，热力图与统计立即更新。
- 页面必须说明：统计只描述嵌入距离在整瓦片上的分布，不构成对 DW 标签正确性的评估。

### 显示自定义

DW 页提供与 AEF 页一致的热力图显示自定义控件，复用同一套渲染函数、常量与夹取规则：

1. **色阶模式**（`BAND_MODES`）：固定分段 / 动态分段，默认动态分段。
   - 非负量（本页恒为 `d`）的固定分段量程为 `[0, 1]`；
   - 动态分段量程为 `[0, x]`，`x` 为当前阈值量程上界；
   - 切换后重新生成热力图与色条。
2. **档数**：整数输入框，默认 12，范围 2–64。
   - 越界输入被夹取到 `[2, 64]` 并回写控件；
   - 清空输入框不改变当前档数，控件恢复为上一值；
   - 非数字输入同样回退为上一值。
3. **档间边界线**：开关，默认开启；关闭后热力图与色条都不再绘制档间等值线。
4. **显示模式**（`MODES`）：半透明红色叠加（默认）/ 二值掩膜 / 灰底彩色高亮。
   - 二值掩膜模式下不绘制档间边界线，即使开关为开启；
   - 三种模式都保留 `candidate_mask` 轮廓与 bbox 矩形叠加，以及无效像素的中性灰。

约束：

- 这些控件只影响显示：不改变距离数值、阈值、阈值量程、超阈值统计与统计分组。
- 控件只作用于距离热力图与色条；标签图始终按官方配色全彩显示，预览图不受影响。
- 标签图上的 `candidate_mask` 轮廓与 bbox 矩形始终显示，不提供显隐开关。
- 切换任一控件后热力图与色条立即更新，无需刷新页面。

- 切换后重扫瓦片、标签、过渡掩膜、manifest、预览图与统计；原瓦片不存在时回退到第一个含 DW 标签的瓦片。
- 掩膜来源、`gallery` 回退、视图命名差异在状态区以可读文本说明（例如“掩膜来源 = DW valid_mask[0] & valid_mask[1]”“图像来源 = preview.png / review.png”）。

### 结果语义提示

页面常驻：

- “传感器内前后两期嵌入距离：同传感器、不同日期，高值表示嵌入差异大。”
- “统计范围为整个瓦片的全部有效像素；`candidate_mask` 仅作叠加显示，不参与统计筛选。”
- “DW 标签为模型分类，非人工核实真值；pmax 为模型概率。”
- 不提供 S2↔S1 跨传感器对比入口或结果；页面可注明“本页不做跨传感器比较”。

### 布局

- 与 AEF 页一致的三栏布局与滚动规则：左栏控制/元信息/图例/统计，中栏标签图与热力图，右栏预览图。
- 整页不滚动，三栏各自独立纵向滚动；标题栏以下高度填满视口。

## 服务与运行

- 入口为 `app/change_detection_webui.py`，使用 NiceGUI 启动；页面与数据访问拆分到 `app/webui/` 模块。
- 默认监听 `127.0.0.1:8080`，主机与端口可由命令行参数覆盖。
- 页面初次加载时自动选中默认瓦片、默认组合类型、默认视图和默认阈值，无需用户操作即可看到完整结果；DW 页在默认数据根可用时自动加载第一个 DW 瓦片与默认传感器。
- 所有依赖安装在项目 `.venv`，运行命令使用 `.venv/Scripts/python.exe`。
- 不新增第三方依赖；不修改 `data/` 与 DW 数据包内任何文件。
- 不访问网络；图像与数据全部来自本地文件。
- 命令行参数：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `--host` | `127.0.0.1` | 监听地址 |
| `--port` | `8080` | 监听端口 |
| `--data-root` | `data/spectral` | AEF 页初始数据包根目录 |
| `--dw-data-root` | 仓库同级 `AEF_DW_change_data_20261031` | DW 页初始数据包根目录 |
| `--show` | 关闭 | 启动后自动打开浏览器 |
