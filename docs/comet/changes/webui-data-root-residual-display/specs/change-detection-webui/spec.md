# 变化检测 WebUI 规格

## 目的

本 capability 提供一个本地 NiceGUI 应用，按 AlphaEarth Foundations (AEF) 论文补充材料 S4.1 的无监督变化检测流程，对同一瓦片像素嵌入做逐像素比较，输出可交互的变化程度热力图，并与数据包 `gallery` 中的原始图像并排呈现。

应用支持三种组合类型：

1. **同通道跨日（同模态对照）**：同一瓦片、同一传感器、同一 view 的两帧比较，保留现有行为。
2. **同日跨通道（跨模态基线）**：同一瓦片、同一传感器、同一日期、两个不同 view。输出通道差异基线，**不是变化检测结果**。
3. **跨日跨通道（跨模态变化，探索性）**：同一瓦片、同一传感器、两个不同 view，各自取不同日期。输出扣除同日基线后的残差。

数据根目录可由用户在界面中指定（默认 `data/spectral`），切换后无需重启进程即可浏览另一个数据包。

数据集不提供变化参考标注，所有结果只能作为探索性对照；界面不得出现准确率、置信度或真值类结论。

## 输入数据契约

### 数据根与路径解析

- 默认数据根为仓库内 `data/spectral`；启动参数 `--data-root <path>` 可覆盖初始数据根。
- 界面中的路径控件接受绝对路径，也接受相对仓库根目录的路径。
- 解析规则：
  1. 目录必须存在，否则拒绝应用。
  2. 若目录下存在 `tiles/` 且有至少一个瓦片子目录，则该目录即数据根，`tiles/` 为瓦片目录。
  3. 否则若目录下恰有一个非 `tiles` 命名的瓦片容器，则该目录即数据根，该容器为瓦片目录；若存在多个候选容器，拒绝应用并列出候选名，不做猜测。
  4. 否则若目录自身直接包含瓦片子目录，则该目录即瓦片目录（名称不限），数据根取它的父目录。
  5. 其余情况拒绝应用。
- 输入框默认显示数据根路径；若瓦片目录名不是 `tiles`，则显示该瓦片目录路径，保证「显示值再次应用」得到同一结果。
- 不支持符号链接 / 目录联接：瓦片目录与 `gallery/` 必须是数据根内的真实目录；经链接解析到数据根之外的图像记录按无效处理。
- 瓦片子目录的判定：子目录下存在 `embeddings/` 目录或 `tile_manifest.json`。
- 数据访问对象必须显式记录「数据根 + 瓦片目录」两个位置，使非 `tiles` 命名的瓦片容器也能正确读取；`gallery/` 始终相对数据根解析。
- 提交前预检：在切换生效前必须完成瓦片枚举与每个瓦片 manifest 的读取（用于下拉标签），并确认目标瓦片至少有一个嵌入视图；任一步失败都按「应用失败」处理。
- 切换生效后的界面重建若仍抛错，必须回滚到切换前的数据根、瓦片列表与选择状态，并显示错误原因。
- 切换数据根必须重建数据访问对象并清空全部缓存（嵌入、帧元数据、掩膜、manifest、视图列表、旋转图、gallery 索引），不得跨目录复用。
- 应用失败时保留当前数据根与当前显示结果不变，并在路径控件旁显示错误原因。

### 嵌入

- 路径：`<数据根>/<瓦片目录>/<tile>/embeddings/<view>.npy`（默认瓦片目录名为 `tiles`）
- 形状：`(frames, 128, 128, 64)`，`float32`，每像素向量已为单位长度。
- 帧元数据：同目录 `<view>_index.json`，`frames[i]` 提供 `date_utc`、`timestamp_ms`、`parent_raw_index`、`sensor_id` 等字段。

### 瓦片清单

- 路径：`<数据根>/<瓦片目录>/<tile>/tile_manifest.json`。
- 用于瓦片下拉的类别/split 标签，以及坐标信息的唯一来源。

### 坐标信息

- `tile_manifest.json` 的 `parent` 字段形如 `registered/tiles/C01_E121.4790_N25.1724_20240101_20241231`，中心经纬度编码在目录名中。
- 解析规则：在 `parent` 中匹配 `_<E|W><经度>_<N|S><纬度>` 形式；`W`、`S` 取负值。
- 展示：`中心坐标 = 121.4790°E / 25.1724°N`，并附 `原始父目录 = <parent 原字符串>`。
- `parent` 缺失、不含坐标、数值越界（|lon| > 180 或 |lat| > 90）或解析失败时显示 `中心坐标 = 无坐标信息`，不得抛出异常，不得隐藏该行。

### 视图与传感器

- view 名形如 `<sensor>_<bandset>`，传感器前缀为 `sentinel2` 或 `landsat`。
- Sentinel-2 视图：`full`、`visible`、`nir`、`swir`、`reflective_ir`。
- Landsat 视图：`full`、`visible`、`nir`、`swir`、`thermal`。
- `full` 是唯一分布内视图；其余单通道或组合通道视图均为波段消融的**分布外诊断**，界面必须逐通道标注。
- 同一瓦片同一传感器下，各 view 的 `date_utc` 与 `parent_raw_index` 完全一致（同一成像），因此同日期、同帧序号的跨 view 取帧对应同一次观测。
- 数据规模（默认数据包）：Sentinel-2 共 33 个瓦片（32 个两期 + V01 三期，共 67 个 epoch）；Landsat 共 20 个瓦片（12 个两期 + 8 个仅一期，共 32 个 epoch）。8 个单期 Landsat 瓦片为 C05/C06/C10/C12/C17/C18/C19/C21，其 Landsat 视图只有 1 帧。
- 跨传感器比较不在本 capability 内；跨通道的 A、B 通道必须属于同一传感器。

### 有效像素掩膜

- 路径：`<数据根>/<瓦片目录>/<tile>/distance_maps/<sensor>_*.npz` 中的 `common_mask`，`bool`，形状 `(128, 128)`。
- `<sensor>` 取 view 名的前缀（`sentinel2` 或 `landsat`）。同一瓦片下不同传感器各有独立掩膜，必须按传感器选取，不得取目录中第一个文件，也不得回退到其他传感器的掩膜。
- 同一瓦片同一传感器内，所有 view 共用同一 `common_mask`（53 组已验证）；因此跨通道可直接复用，但不得跨传感器复用。
- 缺失对应传感器的掩膜时必须报错，不得使用全 True 掩膜。
- 掩膜的使用受界面开关控制：开关关闭（默认）时不应用掩膜，全部像素参与着色与统计；开关开启时，掩膜为假的位置不参与任何统计且热力图中以中性灰显示。
- 掩膜外的嵌入向量本身可能包含有效数值（实测 C01 的 413 个掩膜外像素范数为 1、无 NaN、两帧互不相同），因此关闭掩膜后必须按正常距离着色，不得因为“曾被掩膜排除”而输出灰块或异常颜色。

### 图像

- `<数据根>/gallery/index.json` 为数组，元素含 `id`、`source`、`date`、`image`；`image` 以打包时的根目录名为前缀（默认数据包为 `spectral/`）。
- 路径解析顺序：先去掉首段前缀后按本数据根解析，再按原样相对本数据根解析；只有当前缀确实等于本数据根的目录名时才使用「数据根父目录 + 原路径」。这样把数据包复制或改名到同一父目录下时，不会静默读到原数据包的图像。
- 解析结果必须落在数据根之内：绝对路径、含 `..` 的路径或解析后越出数据根的记录一律视为无效，不得读取包外文件。
- 索引不是数组时按无效索引处理并报错；某条记录的 `id`/`source`/`date` 不是非空字符串、`image` 不是字符串或无法解析到包内文件时，跳过该条记录，不得抛未捕获异常。
- 以 `(id=tile, source=encoder_source, date=date_utc)` 为键精确匹配该帧的 PNG，默认数据包共 98 条唯一键；每个瓦片-传感器-日期只有一张整幅图。
- 默认数据包唯一缺图为 V01/sentinel2/2024-09-01：索引无该记录。
- gallery 文件按 `{tile}_{source}_{帧序号}.png` 命名，日期到文件名的映射只能经 index 完成。缺失提示必须说明该命名模式与当前瓦片已有文件，不得拼接日期形状的伪文件名。
- 缺失提示区分两种情况：索引无该日期记录；索引有记录但文件不存在（后者给出记录中的路径）。
- 数据根下没有 `gallery/index.json` 时，所有图像查询按“索引无该日期记录”处理，不阻止数据根切换。
- gallery PNG 为预渲染多面板图：Sentinel-2 为 RGB/NIR/SWIR 三面板，Landsat 为 RGB/NIR/SWIR/Thermal 四面板，每面板 256×256，纵向位于第 48–303 行；本 capability 按原样完整显示，不裁剪。

### 组合规模

按全部 5 个视图（含 `full`）计：

- 同日跨通道：990 组（Sentinel-2 670 / Landsat 320）。
- 跨日同通道：235 组（Sentinel-2 175 / Landsat 60）。
- 跨日跨通道：470 组（Sentinel-2 350 / Landsat 120）。

若只计四个严格单通道（排除 `full`），对应为 594（402/192）、188（140/48）、282（210/72）；跨日类共 45 个多期瓦片-传感器组。

## 组合类型

界面必须提供组合类型选择器，切换后下方控件、热力图、gallery 图像与统计同步更新，无需刷新页面。三个选项及说明：

| 值 | 界面标签 | 语义说明 |
| --- | --- | --- |
| `same_channel` | 同通道跨日（同模态对照） | 同一视图不同日期；高值 = 变化程度 |
| `same_day` | 同日跨通道（跨模态基线） | 同一日期两个通道；高值 = 通道差异基线，不代表变化 |
| `cross_day` | 跨日跨通道（跨模态变化） | 两个通道不同日期；显示扣除同日基线后的残差，探索性对照 |

当前结果所属类型必须始终显示在结果区，不能只靠选择器控件隐含表达。

## 计算

### 距离

对两个帧 `i`、`j` 的嵌入张量 `X`、`Y`，逐像素计算：

```
cos(p) = <X[p], Y[p]> / (||X[p]|| * ||Y[p]||)
d(p)   = (1 - cos(p)) / 2
```

实现要求：

- 计算前对每个像素向量做 L2 归一化；零范数向量按无效处理。
- `d` 的取值截断在 `[0, 1]`。
- 该定义与论文公式 (8) 一致，`0` 表示两帧完全相同，`1` 表示方向相反。
- 必须独立于数据包自带的 `distance_maps` 数值实现；后者仅用于读取 `common_mask`。
- 数据集自带的 `C0_epoch_*`、`C1_*`、`same_modality_*` 使用 `1 - cos`，是本实现 `d` 的 2 倍；界面与统计不得混入这些数值。严格 2 倍关系可用于验收比对，不得用于展示。

### 同通道跨日

保持现有实现：同一 view 的两帧 `i < j`，输出 `d(X[i], Y[j])`。

### 同日跨通道

同一瓦片、同一传感器、两个不同视图 A、B，取同一帧序号 `t`（同一日期）：

```
base(p) = d(A[t], B[t])
```

输出 `base` 作为基线图。基线高值表示两通道之间的固有差异，不是变化。该类型必须保留阈值、高亮与超阈值统计（阈值作用于基线值），并在界面明示“高值 = 通道差异基线，不代表变化”。

### 跨日跨通道

同一瓦片、同一传感器、两个不同视图 A、B。A 的所选帧序号为 `ref`，其日期为参考日期；B 的所选帧序号为 `other`，且日期必须不同（`other != ref`）。

```
base(p) = d(A[ref], B[ref])                    # 参考日期的同日基线
fwd(p)  = d(A[ref], B[other]) - base(p)        # 正向残差
rev(p)  = d(B[ref], A[other]) - base(p)        # 反向残差
sym(p)  = (fwd(p) + rev(p)) / 2                # 对称化残差
```

- `base`、`fwd`、`rev`、`sym` 取值截断在 `[-1, 1]`。
- `sym` 必须按上式逐像素计算，不得用两个方向的均值距离再减去基线以外的其他口径。
- 三个残差均带符号：负值表示该跨日期距离低于参考日期的同日基线（通道差异减弱），正值表示高于基线（通道差异增强）。

## 阈值量程

阈值控件的量程随当前被可视化的非负量自适应，不再固定为 `[0, 1]`。

记当前被可视化的量（非负）为 `q`，参与统计的像素集合为 `S`（由 `common_mask` 开关决定），`m = max(q[p] for p in S)`。量程为左开右闭的 `(0, x]`：左端 `0` 不提供，最小可选值为一个步长。

- 同通道跨日：`q = d`。
- 同日跨通道：`q = base`。
- 跨日跨通道：`q = |r|`，`r` 为当前选中的残差（fwd / rev / sym）。带符号视图下阈值仍然作用于 `|r|`，不是作用于带符号值本身。

量程规则：

1. 步长 `step` 取约 `m/100`，保留到合适精度（不小于 `0.0001`），使量程小时仍有约 100 个档位。
2. 上界 `x` 取严格大于 `m` 并对齐到 `step` 的最小值，即 `x = ceil(m / step + ε) * step`，并截断到 `1.0`。
   - 必须保证 `count(q > x) == 0`，即滑块到达上界时没有任何高亮像素。
   - 量程左端为排除值：滑块与数值框的最小值均为 `step`，因此阈值永远取不到 `0`，实际可选范围为 `(0, x]`。
   - 若 `m == 0`（所有像素量为 0），令 `x = step`，此时最小值与最大值同为 `step`，任何阈值下高亮数均为 0。
3. 默认阈值：
   - 当 `x >= 0.30` 时取 `0.30`；
   - 当 `x < 0.30` 时取 `x / 2`；
   - 均对齐到 `step` 并限制在 `[step, x]`（左端不可为 0）。
4. 切换组合类型、数据根、瓦片、视图/通道、帧（对）或 `common_mask` 开关时，重新计算 `step`、`x` 与默认阈值。

## 统计

在参与统计的像素集合内计算。该集合由 `common_mask` 开关决定：开启时为掩膜内像素，关闭时为全部 16384 个像素。

通用统计（三类组合均保留）：

- 参与统计的像素总数；
- 高于阈值的像素数与占比 `count / total`；
- 当前可视化量的中位数、p95、最大值。

其中“高于阈值”统一按 `q > threshold` 判定：非负量视图 `q` 即其本身；跨日跨通道带符号视图 `q = |r|`。中位数/p95/最大值按当前可视化量计算：带符号视图下分别为 `median(r)`、`percentile(r, 95)`、`max(r)`，并额外显示 `min(r)`；绝对值视图与另两类组合按非负量计算。

跨日跨通道额外显示（无论当前选中哪个残差视图，均同时显示）：

- 同日基线均值 `mean(base)`；
- 正向残差均值 `mean(fwd)`；
- 反向残差均值 `mean(rev)`；
- 双向均值之差 `mean(fwd) - mean(rev)`（带符号显示）；
- 对称化残差均值 `mean(sym)`。

统计标签必须说明当前可视化量、阈值作用对象（`q` 或 `|r|`）与分母来自哪种掩膜状态，避免把不同口径的数字混淆。

统计使用连续量，与色阶是否分档无关。

## 界面

### 控件

1. **数据根目录**：文本输入框加“应用”按钮。输入框初值为当前生效的数据根绝对路径（默认 `data/spectral`）；若瓦片目录名不是 `tiles`，则显示该瓦片目录路径，以便原样再次应用。应用按钮按「数据根与路径解析」规则校验并切换。切换成功后状态行显示新的数据根路径；失败时显示错误原因且不改变当前结果。输入框旁说明可接受的两种目录形态。
2. **组合类型选择器**：三个选项，见「组合类型」，默认 `same_channel`（保持现有默认体验）。
3. **瓦片选择器**：列出当前数据根下的瓦片目录（默认名 `tiles`）中全部瓦片，显示类别和 split 作为辅助信息。切换数据根后重新枚举。
4. **瓦片坐标信息**：紧接瓦片选择器下方，显示当前瓦片的中心经纬度与原始父目录名；无坐标时显示“无坐标信息”。切换瓦片时同步更新。
5. **通道选择**：
   - 同通道跨日：单一视图选择器，列出可做两帧比较的视图，默认 `sentinel2_full`；被排除的单帧视图在元信息中说明。
   - 同日跨通道 / 跨日跨通道：A、B 两个视图选择器，按「视图可用性过滤」约束；切换 A 后 B 的选项随之更新。
6. **帧选择**：
   - 同通道跨日：帧对选择器，仅当 `frames > 2` 时出现。
   - 同日跨通道：单一帧选择器。
   - 跨日跨通道：A 帧、B 帧两个选择器。
7. **残差视图选择器**（仅跨日跨通道）：
   - 残差方向：正向 / 反向 / 对称化，**进入该组合类型时默认「正向」**。
   - 残差取值：带符号 / 绝对值，**进入该组合类型时默认「绝对值」**。
   - 从其他组合类型进入跨日跨通道（含首次进入）时重置为上述默认；在同一组合内切换瓦片、通道或帧时保留用户当前选择。
   - 另提供当前选中的单向/对称化说明文字与公式。
8. **色阶分层控件**（三种组合类型都显示、都生效）：
   - 色阶模式：固定分段 / 动态分段，默认「动态分段」。
   - 档数：整数输入，范围 2–64，默认 12。
   - 档间边界线：开关，默认开启。
   - 三项改动后立即重绘热力图与色条，不触发阈值重算。
9. **阈值滑块**：量程 `(0, x]` 由当前可视化量自适应计算（见「阈值量程」），最小值为 `step`、最大值为 `x`，步长自适应；同时提供数值输入框，其最小值同为 `step`，二者双向同步，数值精度随量程调整。滑块与数值框均需实时显示当前阈值，并显示当前量程上界 `x`。带符号视图必须写明“阈值与高亮作用于 |残差|”。
10. **显示模式选择器**：三种模式，见下节。默认「半透明红色叠加」。
11. **common_mask 开关**：默认关闭（全部像素参与着色与统计）。开启时应用掩膜，掩膜外像素显示中性灰且不计入统计；关闭时全部像素参与着色与统计。切换后无需刷新页面即可看到热力图与统计变化。

### 视图可用性过滤

- **同通道跨日**：只列 `frames >= 2` 的视图（现有行为）；单帧视图在元信息中列出并说明排除原因。
- **同日跨通道**：列该瓦片全部视图（两传感器共 10 个），要求 A、B 同传感器且不相同；单帧视图可参与（因为不需要两期）。
- **跨日跨通道**：只列 `frames >= 2` 的视图；单期 Landsat 瓦片的 Landsat 视图不得出现在 A 或 B 的可选项中，因此不会产生不可算组合。
- 跨通道类型中，A 选择器列出全部可用视图；B 选择器只列与 A 同传感器且不同于 A 的视图。切换 A 的传感器时，B 自动重置为该传感器下第一个不同于 A 的视图。
- 默认：A = `sentinel2_visible`，B = `sentinel2_nir`；若不可用，回退到该瓦片第一个可用传感器的前两个不同视图。跨日跨通道的 A 帧默认 0、B 帧默认最后一个日期不同于 A 的帧。
- 切换数据根后，若原瓦片仍存在则保留；否则自动选择新数据根中排序后的第一个瓦片，并重置视图/通道/帧默认值。

### 结果语义提示

结果区必须常驻显示当前组合类型及其语义提示：

- 同通道跨日：“同模态对照：同一视图不同日期，高值表示变化程度。”
- 同日跨通道：“跨模态基线：同一日期的通道差异，高值不代表变化。”
- 跨日跨通道：“跨模态变化（探索性）：残差 = 跨日期距离 − 同日基线；数据不含变化参考标注，仅作探索性对照。”

### 热力图

以 `128 x 128` 场为数据源，按档离散着色并显示色条。

#### 色域

记当前被显示的量 `v`：非负量（同通道距离、同日基线、绝对值残差）为 `q`；带符号残差为 `r`。

| 色阶模式 | 非负量色域 | 带符号残差色域 |
| --- | --- | --- |
| 固定分段 | `[0, 1]` | `[-1, 1]` |
| 动态分段 | `[0, x]` | `[-x, x]` |

- `x` 为当前阈值量程上界（见「阈值量程」），与阈值控件最大值完全一致；掩膜开关、组合类型、瓦片、视图、帧变化导致量程重算时，动态色域同步更新。
- 固定模式不随数据变化；动态模式把当前数据覆盖的实际区间映射到完整色带。

#### 分档与配色

1. 归一化位置 `t = clip((v - lo) / (hi - lo), 0, 1)`；当 `hi == lo` 时令 `t = 0`。
2. 档位 `k = min(floor(t * levels), levels - 1)`，`k ∈ [0, levels-1]`。
3. 第 `k` 档的颜色取颜色表在归一化位置 `(k + 0.5) / levels` 处的插值颜色：
   - 非负量使用顺序色表（现有 11 档 inferno 风格色表）；
   - 带符号残差使用发散色表（现有 9 档蓝 → 近白 → 红色表），`0.5` 位置为中性白。
4. 同一档内所有像素颜色完全相同；颜色表本身与既有实现一致，只改变采样粒度（由连续插值改为按档采样）。
5. 固定模式下各档颜色在色带上等距分布；动态模式下各档仍覆盖色带全跨度（首档接近起点颜色，末档接近终点颜色）。
6. 档数为偶数时，带符号残差的 0 值正好落在档边界上（相邻两档分别位于中性白两侧）；档数为奇数时中性白档以 0 为中心。

#### 档间边界线

- 由量化档位数组 `K` 生成：像素若与右邻或下邻档位不同，则标记为边界像素。
- 边界线开关开启时绘制：依据该处底色亮度选择黑或白线条颜色，并与底色做半透明混合，保证在深色档与浅色档上均可辨。
- 边界线开关关闭时不绘制，档与档之间仅有颜色跳变。
- 边界线只影响显示：不改变档位、阈值判定、超阈值统计、量程或旋转。
- 二值掩膜模式不渲染分档底色，因此该模式不绘制档间边界线；开关状态保留，切回其余两种模式后继续按开关生效。该规则避免等值线覆盖红色掩膜、掩盖真正的高亮结果。

#### 色条

- 色条与热力图使用同一色域、同一档数、同一配色与同一边界线开关，显示为离散色带；端点标注色域上下界，并注明当前模式（固定/动态）与档数。
- 非负量色条标注 `0 → x`（动态）或 `0 → 1`（固定）；带符号残差标注 `−x → 0 → +x`（动态）或 `−1 → 0 → +1`（固定）。
- 带符号残差色条必须注明“负 = 残差减小，正 = 残差增大；阈值与高亮作用于 |残差|”。

#### 其他约束

- 掩膜开关开启时，掩膜外的像素显示为中性灰，不参与色阶；关闭时全部像素按当前量着色。
- 热力图上叠加超阈值区域时，阈值使用滑块当前值；色阶与阈值量程解耦（只有动态模式的色域上界使用该量程的 `x`）。
- **朝向**：热力图必须与右侧 gallery 图像处于同一朝向，即渲染完成后顺时针旋转 90° 再显示；边界线随图一同旋转。旋转只改变显示朝向，不改变 128×128 的像素计数、统计数值或阈值量程。热力图标题必须标注“顺时针旋转 90°”。

### 显示模式

1. **半透明红色叠加**（默认）：在分档着色的底图上，对 `q > threshold` 的像素叠加半透明红色。带符号视图下 `q = |r|`，底图仍按带符号发散色阶分档着色。
2. **二值掩膜**：`q > threshold` 的像素显示为红色，其余有效像素显示为深色；掩膜外仍为中性灰。
3. **灰底彩色高亮**：`q > threshold` 的像素保留分档配色，其余有效像素转为灰度。带符号视图下灰度按 `|r|` 计算。

### 图像区域

- **同通道跨日**：显示与所比较两帧对应的两张 gallery 整幅图，各自标注 `date_utc` 与来源（现有行为）。
- **同日跨通道**：两通道同日期，gallery 只有一张图；只显示一次，标注“同一观测，两通道”并给出 A、B 通道名与日期，不得重复渲染成两张。
- **跨日跨通道**：显示该传感器两个日期对应的整幅图（A 参考日期与 B 目标日期），各自标注日期与通道名。
- **图像朝向**：gallery 图按原样从磁盘读取后，在内存中顺时针旋转 90° 再显示；`data/` 下文件不得被修改。旋转后单张整幅图由横向 `768×340` 变为纵向 `340×768`。旋转结果与热力图保持同一朝向。
- **布局**：图像区位于热力图右侧，两张整幅图**左右并排**（同高度、同一顶边），使两帧画面可同时看到；图像按宽高比缩放，限高为视口高度的 72%，不得拉伸变形。页面上方标注“gallery 原始图像（顺时针旋转 90°，两帧并排）”。
- **同日跨通道**：只有一张图，占左侧一列；右侧列隐藏，不得显示空白占位以外的重复图。
- 图像缺失或匹配失败时，按「图像」契约显示具体缺失的日期、gallery 命名模式与该瓦片现有文件；索引有记录但文件不存在时还要给出记录路径。V01 的 2024-09-01 无索引记录，必须显示“索引无记录”分支。缺图提示需保留换行（多行文本），不得压成一行。

### 元数据展示

在页面上显示：

- 当前数据根路径；
- 当前瓦片的 `split`、`category` 与中心坐标；
- 组合类型名称与语义提示；
- A、B 通道名（同通道跨日为一个视图）、各通道所属传感器、波段标识；
- 各通道的分布内/分布外标记；当两通道分布类别不同时显示“分布内 vs 分布外混合对照”；
- 各通道日期与帧序号；
- 帧数、被排除的视图及原因；
- `common_mask` 像素数（掩膜为真的像素数）；
- 当前距离/基线的中位数、p95、最大值与超阈值像素统计；
- 跨日跨通道的同日基线均值、正向/反向/对称化残差均值及双向均值之差。

界面不得出现准确率、置信度或真值类表述。

### 布局与滚动

页面采用三栏横向布局：左侧控制与统计栏、中间热力图栏、右侧图像栏。

- **整页不滚动**：页面总高度固定为视口高度，浏览器窗口层面不得出现纵向滚动条（`html`/`body` 高度占满且 `overflow: hidden`）。
- **各栏独立纵向滚动**：三栏各自拥有独立的纵向滚动容器，高度等于视口高度。当某一栏内容超出视口时，只滚动该栏，热力图与图像保持原位，不因阅读长文本或操作靠下控件而被滚出窗口。
- **滚动条样式**：独立滚动容器使用细滚动条（约 10px 宽），轨道与滑块颜色区分明显，使“当前是栏内滚动”在视觉上可辨。
- 三栏宽度：左栏 360px 固定、热力图栏 540px 固定、图像栏占剩余宽度；允许横向滚动以适配窄窗口。
- 新增的数据根控件、坐标行与色阶控件都放在左栏内；左栏内容变长时只滚动左栏。布局变化不影响任何数值、统计口径或图像内容。

  - 可选目录（`observations/`、`band_extracts/` 等）不影响运行；
  - 规模参考与「不要把 `data/` 提交进 Git」的提示；
  - 一份可逐条勾选的自检清单。
- 说明书描述的界面行为必须与本文档一致；不得出现准确率、置信度或真值类表述。

## 服务与运行

- 入口为单个 Python 脚本，使用 NiceGUI 启动。
- 默认监听 `127.0.0.1:8080`，主机与端口可由命令行参数覆盖；`--data-root` 可覆盖初始数据根。
- 页面初次加载时自动选中默认数据根、默认瓦片、默认组合类型（同通道跨日）、默认视图和默认阈值，无需用户操作即可看到完整结果。
- 所有依赖安装在项目 `.venv`，运行命令使用 `.venv/Scripts/python.exe`。
- 不新增第三方依赖；不修改数据包内任何文件。
- 不访问网络；图像与数据全部来自本地文件。
