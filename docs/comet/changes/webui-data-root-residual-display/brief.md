# 目标

在现有 AEF 无监督变化检测 WebUI（`app/change_detection_webui.py`，NiceGUI 单文件）中增加四项用户可见能力，并补充一份面向使用者的说明书：

1. **数据文件夹路径可选**：界面提供数据根目录输入框，默认填写当前使用的路径；修改并应用后按新目录重新扫描瓦片、索引与图像，无需重启进程。
2. **跨日跨通道默认口径**：该组合类型的残差默认取「正向」方向与「绝对值」取值。
3. **热力图颜色分层**：残差热力图的颜色区分更明显，增加颜色分层，使相邻数值区间在视觉上可区分。
4. **瓦片坐标信息**：在瓦片选择栏下方显示当前瓦片的坐标信息。
5. **使用说明书**：为当前项目编写一份使用说明书，介绍界面各选项的用法与用途。

# 验收示例

- A1：界面存在数据根目录输入框，初始值等于当前生效的数据根（默认 `data/spectral` 的绝对路径；瓦片目录名不是 `tiles` 时显示该瓦片目录路径，以保证原样再次应用得到同一结果）；输入另一个合法数据包路径并应用后，瓦片下拉、gallery 图像、热力图与统计随新目录更新，无需重启进程；输入不存在或结构不完整的路径时显示错误提示，且不破坏当前已加载的数据（含用户已调阈值）。
- A2：路径解析同时接受数据包根（含瓦片容器与 `gallery/`）与直接包含瓦片子目录的瓦片容器（名称不限）；同一数据根下存在多个候选容器时要求直接指定其中一个；切换后若原瓦片在新根不存在，自动回退到新根内第一个可用瓦片并完成一次完整刷新。
- A3：组合类型切到跨日跨通道时（含首次进入），残差方向为「正向」、残差取值为「绝对值」；离开该组合后再次进入仍回到该默认；用户手动改动后在本组合内切换瓦片/通道/帧保持其选择。
- A4：三种组合类型的热力图都按「档」离散着色：色阶模式可切换「固定分段」与「动态分段」，档数可由整数输入框调整（默认 12），档间等值线边界可开关（默认开启）；固定模式使用全量程（非负 `[0,1]`、带符号 `[-1,1]`），动态模式使用与阈值量程一致的自适应上界 `x`（非负 `[0,x]`、带符号 `[-x,x]`）；色条同步显示离散档位与量程端点；色阶只影响显示，不改变阈值、超阈值统计与量程；二值掩膜模式不绘制档间边界线（其余两种模式按开关生效）。
- A5：瓦片选择器下方显示当前瓦片的中心经纬度（从 `tile_manifest.json` 的 `parent` 解析，如 `E121.4790 / N25.1724`）；切换瓦片时文本同步更新；无坐标信息的瓦片（如 `V01`）显示明确的“无坐标信息”提示而不是空白或错误数值。
- A6：说明书覆盖启动方式、数据路径、组合类型、通道/帧选择、残差方向与取值、阈值、显示模式、common_mask、坐标信息与缺图提示，并对每个选项说明用途与取值含义；文档中的操作与当前实现一致。
- A7：三种组合类型切换、同日跨通道与 C0 的严格 2 倍关系、跨日跨通道残差与对称化公式、单期 Landsat 过滤、掩膜按传感器选取、三栏独立滚动、common_mask 默认关闭等既有行为均不回归。

# 约束与不变量

- 数据包结构：数据根下有且只有一个瓦片容器（默认名 `tiles`，可为其他名称）时，其中含 `<tile>/embeddings/<view>.npy`、`<tile>/embeddings/<view>_index.json`、`<tile>/tile_manifest.json`、`<tile>/distance_maps/<sensor>_*.npz`；`gallery/index.json` 位于数据根下，其 `image` 以打包时的根目录名为前缀。
- 数据访问对象显式记录「数据根 + 瓦片目录」两个位置，使非 `tiles` 命名的容器可用；切换数据根必须整体重建 `Dataset` 实例并清空全部缓存（含 gallery 索引），不得跨目录复用。
- gallery 路径解析必须先去掉打包根名前缀、按本数据根解析，只有前缀确实等于本数据根名时才回落到父目录；解析结果必须落在数据根之内（拒绝绝对路径与含 `..` 的记录），以避免同级同名数据包之间互相读图。
- 切换数据根前必须完成预检（枚举瓦片、逐个读取 manifest、确认目标瓦片至少有一个嵌入视图）；切换生效后的界面重建若仍失败，必须回滚数据根、瓦片下拉、选择状态与阈值控件，并保留用户已调阈值。

- 坐标唯一来源是 `tiles/<tile>/tile_manifest.json` 的 `parent` 字段，形如 `registered/tiles/C01_E121.4790_N25.1724_20240101_20241231`；`V01` 的 `parent` 为 `controls/tiles/V01`，不含坐标。
- 坐标解析失败、字段缺失或格式不符时按“无坐标信息”处理，不得抛出未捕获异常。
- 现有色阶：非负量 11 档顺序色阶、带符号残差 9 档发散色阶。两套颜色表保留，界面改为按档位在颜色表上采样（不再显示连续插值），档数由用户设置。
- 分段着色是纯显示变换：阈值比较、超阈值统计、量程计算仍使用连续量，不得因量化而改变。
- 色阶模式、档数与边界线开关由用户调整后立即生效，不触发阈值重算（动态模式除外：其量程来自当前阈值量程上界，随 rescale 更新）。
- 热力图与 gallery 图像均顺时针旋转 90°；色阶与坐标显示不得改变该朝向或统计数值。
- 缓存（嵌入、元数据、掩膜、manifest、视图、旋转图）必须随数据根切换失效，避免跨目录串用。
- 所有依赖已在 `.venv`（NiceGUI 3.18.0、numpy 2.5.4、Pillow 13.0.0），不新增依赖。

# 决策

- D1（用户确认）：热力图提供「颜色分层」模式切换，共两种模式：
  - **固定分段色阶**：把全量程分成固定档数，档与档之间显示细边界线，边界线可开关；
  - **动态分段色阶**：把当前数据覆盖的较小区间分成同样档数，使用与固定模式相同的完整颜色跨度（同一色带从一端到另一端），量程取值与阈值量程的选择逻辑保持一致。
- D2（用户确认）：使用说明书以仓库内 Markdown 文档交付。
- D3（用户确认）：瓦片坐标显示中心经纬度与原始父目录名。
- D4（用户确认）：颜色分层对三种组合类型全部生效，控件常驻。
- D5（用户确认）：动态模式的取值范围与阈值量程逻辑一致，即取自适应量程上界 `x`（`step ≈ max/100`、`x = ceil(max/step)*step` 并截断到 1.0）；非负量域 `[0,x]`，带符号残差域 `[-x,x]`。
- D6（用户确认）：分层控件默认值为「动态 · 12 档 · 边界开启」。
- D7（实现选择）：档间边界按量化后相邻像素的档位差生成，形成随数据形状走的等值线，而不是固定网格线；顺序色阶与发散色阶共用同一套量化逻辑。
- D8（实现选择）：数据根解析同时接受数据包根（含唯一瓦片容器）与瓦片容器本身；多个候选容器时拒绝并要求直接指定；无法解析时拒绝并保留当前数据。
- D9（实现选择）：切换数据根时整体重建 `Dataset`（携带「数据根 + 瓦片目录」），不复用旧实例缓存。
- D10（实现选择）：残差默认只在进入跨日跨通道时重置；同组合内切换瓦片/通道/帧时保留用户当前选择。
- D11（实现选择）：坐标缺失时显示“无坐标信息”，不隐藏该行。
- D12（实现选择）：二值掩膜模式不绘制档间边界线，避免等值线覆盖红色高亮；开关状态保留，切回其余两种模式后继续生效。
- D13（实现选择）：不支持符号链接 / 目录联接；瓦片目录与 `gallery/` 必须是数据根内的真实目录，指向包外的图像记录按无效处理。
