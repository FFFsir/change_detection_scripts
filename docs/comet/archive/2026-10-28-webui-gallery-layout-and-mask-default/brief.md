# 目标

在已完成跨通道组合类型的 WebUI（`app/change_detection_webui.py`）上完成四项用户可见的界面调整，并把期间在 Comet 流程外完成的改动正式纳入规格与验收：

1. **gallery 图像旋转并排**：原始整幅图在内存中顺时针旋转 90°，两张图左右并排显示，使两帧画面在页面中同时可见。
2. **热力图同向旋转**：热力图与右侧图像保持同一朝向（同样顺时针旋转 90°），避免两者相差 90° 造成空间误读。
3. **三栏独立纵向滚动**：禁止整页滚动，左栏、热力图栏、图像栏各自独立纵向滚动，阅读长文本时图像不被滚出窗口。
4. **common_mask 默认关闭**：页面初始状态为全部像素参与着色与统计。

# 范围

- 修改 `app/change_detection_webui.py`（保持单文件、NiceGUI）。
- 更新完整目标规格 `docs/comet/changes/webui-gallery-layout-and-mask-default/specs/change-detection-webui/spec.md`（归档时替换 `docs/comet/specs/change-detection-webui/spec.md`）。

# 验收示例

- A1：gallery 图像顺时针旋转 90° 后左右并排显示，两帧同高同顶边、同时可见；同日跨通道只显示一张；`data/` 下文件未被修改；缺图提示保留多行换行。
- A2：热力图与 gallery 图像使用同一顺时针 90° 变换（元素级一致），标题标注旋转；旋转不改变统计数值与阈值量程。
- A3：整页不产生纵向滚动（`scrollHeight == clientHeight`、`window.scrollY` 恒为 0）；三栏各自可独立纵向滚动；滚动左栏时热力图与图像的屏幕 y 坐标不变。
- A4：页面初始 `common_mask` 开关为关闭，统计分母为 16384、热力图无中性灰掩膜块；开启后分母变为掩膜像素数并出现灰色掩膜块；切换时阈值量程按当前像素集合重算。
- A5：三种组合类型切换正常；同日跨通道数值可由独立 numpy 复算逐像素复现且与 C0 严格 2 倍；跨日跨通道残差与对称化公式成立；8 个单期 Landsat 瓦片跨日类型无 Landsat 视图；掩膜仍按传感器选取。

# 约束与不变量

- 距离口径 d=(1-cos)/2 独立于 `distance_maps` 自带数值；后者仅用于读取 `common_mask`。
- `common_mask` 按 view 前缀的传感器选取，不得跨传感器复用，缺失时报错不得回退全 True。
- 同通道跨日的**数值与旋转前 RGB 渲染**必须与改动前的已归档版本字节级一致；由于显示层新增顺时针 90° 旋转，最终显示的 PNG 会与归档版本不同，这是本 change 的预期变更，不属于回归。
- 旋转为纯显示变换：128×128 的像素计数、统计集合与阈值量程的取值范围均不因旋转改变。
- 已归档 change `webui-cross-channel-change` 的 7 项验收结论保持有效，本 change 只做界面调整与默认值变更。

# 决策

- D1（用户确认）：图像顺时针旋转 90° 后**左右并排**（而非上下堆叠），确保两帧同时可见。
- D2（用户确认）：热力图**跟随做同样的顺时针 90° 旋转**，与图像保持同朝向，并在标题中标注。
- D3（用户确认）：三栏各自独立纵向滚动，整页禁止滚动。
- D4（用户确认）：`common_mask` 默认关闭。
- D5（实现选择）：旋转在内存中完成并缓存为 PNG data URL（12 条 LRU），不写 `data/`；图像按旋转后实际宽高比以固定高度（72vh）缩放，避免拉伸。
