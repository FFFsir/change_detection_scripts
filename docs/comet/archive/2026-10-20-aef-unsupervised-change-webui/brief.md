# 目标

提供一个基于 NiceGUI 的本地 WebUI，按 AEF 论文的无监督变化检测流程（S4.1 公式 8）展示单瓦片两帧之间的像素级变化程度：

- 对同一 view 的两帧 64 维单位向量做逐像素比较，得到论文口径的距离 `d = (1 - cos) / 2`，取值域 `[0, 1]`；
- 生成 `128 x 128` 的变化程度热力图，并与 `data/spectral/gallery` 中该瓦片对应日期的图像并排显示；
- 提供自适应量程的阈值控件：量程为 `(0, x]`，左端不可取到 `0`（最小可选值为一个步长），`x` 是当前图像对"超阈值像素数归零"的边界（取略大于最大距离并向上对齐到步长的值，确保滑块到达 `x` 时正好没有高亮），实时在热力图上标出 `d` 高于阈值的像素，并显示这些像素的数量与占比；
- 提供 `common_mask` 开关，用户可决定是否使用该掩膜排除像素；关闭后全部像素参与着色与统计。

# 范围

- 数据源固定为项目内 `data/spectral/tiles/<tile>/embeddings/<view>.npy`，掩膜取该 view 所属传感器的 `distance_maps/<sensor>_*.npz` 中的 `common_mask`。
- 覆盖全部瓦片：33 个瓦片共 265 个 view，其中 225 个可用于两帧比较。剩余 40 个是 C05/C06/C10/C12/C17/C18/C19/C21 的 Landsat 视图，只有 1 帧，无法构成变化检测，界面不列出并在元信息中说明被排除的视图名。V01 的 5 个视图为 3 帧。
- 帧对默认取该 view 的首帧与末帧；`frames > 2` 的瓦片（仅 V01）额外允许选择任意两帧。
- 图像侧使用 `data/spectral/gallery/index.json` 将 `(tile, encoder_source, date_utc)` 映射到 PNG。已核对：225 个可用 view 的首末帧共 450 个日期全部能在 index 中精确匹配到文件。gallery 文件按 `{tile}_{source}_{帧序号}.png` 命名，因此缺失提示需说明该命名模式与现有文件，而不是拼一个日期文件名。
- WebUI 至少包含：瓦片选择、视图选择、帧对选择（仅多帧瓦片）、自适应量程阈值滑块、`common_mask` 开关、热力图、gallery 图像、超阈值像素统计。
- 距离计算在请求时按需完成，不落盘中间产物。

# 非目标

- 不实现 AEF 论文的另一种方法（直接分类变化 / direct classification），该方法需要带标签训练集，本任务只做无监督路径。
- 不做跨瓦片横向对比、批量导出、异常连通域分析或聚类分析。
- 不修改 `data/` 下的任何原始数据。
- 不做多用户部署、鉴权、持久化数据库或远程服务化。
- 不重新训练或修改编码器，不改变嵌入向量本身。

# 验收示例

- A1：启动应用后，默认加载一个瓦片与视图，页面同时呈现该 view 两帧之间的变化热力图，以及与这两帧日期对应的 gallery 图像。
- A2：热力图颜色由 `d = (1 - cos) / 2` 计算，取值与像素级计算一致，范围为 `[0, 1]`；任意像素的计算结果与直接用 numpy 对嵌入向量求 `1 - dot` 再除以 2 得到的值一致。
- A3：页面上存在一个阈值控件，其量程为 `(0, x]`：`x` 由当前图像对自动计算并满足"阈值等于 `x` 时高于阈值的像素数为 0"，左端无法取到 `0`（最小值为一个步长）。拖动后无需刷新页面即可看到高于阈值的像素在热力图上被高亮，且滑块到顶时高亮数恰为 0。
- A4：页面显示当前阈值下高于阈值的像素数量与占比，数值随阈值变化实时更新。
- A5：切换瓦片或视图后，热力图与 gallery 图像同步更新，且显示的图像日期与该 view 所比较的两帧日期一致。
- A6：对于 `frames > 2` 的 V01，可以选择不同的帧对；选择变化后热力图随之更新。
- A7：页面提供 `common_mask` 开关，默认开启。开启时掩膜外像素在热力图中显示为中性灰且不计入统计；关闭后全部 16384 个像素都按距离着色并计入统计，热力图上不再出现中性灰块，统计分母随之从有效像素数变为全部像素数。切换开关无需刷新页面即可看到结果变化。

# 约束与不变量

- Python 依赖安装在项目 `.venv`（`D:\Project\光机所项目\change_detection_scripts\.venv`），使用 `.venv/Scripts/python.exe` 运行与验证，不污染全局环境。
- 距离必须使用论文公式 `d = (1 - cos) / 2`，而不是 `1 - cos`。
- 阈值控件量程随当前图像对自适应，上界 `x` 必须满足 `count(d > x) == 0`；不得再使用固定 `[0, 1]` 量程。量程左端为排除值，滑块最小值等于一个步长，因此阈值永远不为 0。
- 滑块步长自适应，约为 `x/100`，保证小量程图像对（如最大距离约 0.02 的瓦片）仍有足够的可调档位；数值框精度随量程自动调整。
- 切换瓦片、视图、帧对或 `common_mask` 开关后，量程与默认阈值重新计算；默认阈值取 `0.30`（当 `x >= 0.30`）或 `x/2`（当 `x < 0.30`），对齐到步长并限制在 `[step, x]` 内。
- 统计默认只在 `common_mask` 为真的像素上进行；掩膜外像素在热力图中以中性灰显示且不参与计数。`common_mask` 开关关闭时，全部像素参与着色与统计。
- 嵌入向量读取后按论文要求做 L2 归一化再计算。
- 页面必须在本地可启动且无外部网络依赖；图像由本地文件提供。
- 服务默认绑定 `127.0.0.1`，端口可配置。

# 决策

- 距离口径：采用论文 S4.1 公式 (8) `d = (1 - cos) / 2`，单像素距离域仍为 `[0, 1]`；但阈值控件量程改为自适应 `(0, x]`（用户新需求），左端不可取到 0，`x` 使高亮数归零。
- 阈值量程：`x` 取"略大于当前图像对的最大距离并向上对齐到步长"的值，确保滑块到顶时刚好没有高亮；步长取约 `x/100`；默认阈值按 `x >= 0.30 ? 0.30 : x/2` 计算并对齐步长。
- 视图范围：只列出可做两帧比较的 225 个 view，默认 `sentinel2_full`；40 个单帧 Landsat 视图排除并在界面说明（对单帧自比会产出恒为 0 的假结果）。
- 帧对：默认首帧 vs 末帧；V01 支持任意两帧。
- 无效像素：默认用 `common_mask` 排除，热力图以中性灰渲染；同时提供 `common_mask` 开关，关闭后不再排除，全部像素参与着色与统计（用户新增需求）。
- 图像形式（用户选择）：显示 gallery 的**原始整幅图**，不做裁剪，保留标题、全部波段面板与底部说明文字。两帧各自一张，按日期标注并与热力图并排。
- 高亮方式（用户选择）：提供**可选显示模式**，用户可在三种模式间切换：半透明红色叠加、二值掩膜、灰底彩色高亮。默认使用半透明红色叠加。
- 布局：热力图位于一侧，两帧原始整幅图在另一侧纵向排列并标注日期；整幅图较宽，容器允许横向滚动。

# 验证预期

- 用 `.venv/Scripts/python.exe` 启动应用，确认页面可访问且无报错。
- 对至少一个瓦片，将页面显示的 `d` 与独立 numpy 复算结果比对，确认一致。
- 拖动阈值，确认高亮像素与统计数字随之变化；拖到量程上界 `x` 时高亮数必须为 0。
- 切换瓦片/视图，确认量程与默认阈值随图像对重算；小量程瓦片（如最大距离约 0.02）仍有足够可调档位。
- 切换瓦片/视图，确认热力图与图像同步更新且日期匹配。
- 确认 `common_mask` 开启时掩膜外像素不影响统计；关闭后全部像素参与统计且热力图上不留中性灰。
- 确认掩膜外的嵌入向量本身是有效值（非零、非 NaN、范数为 1），因此关闭掩膜能正常着色而非显示为异常颜色。
