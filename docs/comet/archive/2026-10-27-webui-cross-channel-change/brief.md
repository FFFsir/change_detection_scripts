# 目标

在现有 AEF 无监督变化检测 WebUI（`app/change_detection_webui.py`，NiceGUI 单文件）中新增“两张图跨通道”的变化检测组合类型，并保留现有行为：

1. **同日跨通道（基线型）**：同一日期、同一传感器、两个不同 view。输出 d(A_t, B_t) 作为跨模态基线图，高值是通道差异，不是变化。
2. **跨日跨通道（变化型）**：同一传感器、两个不同 view、各自不同日期。输出扣除同日基线后的残差，作为跨模态变化检测的探索性对照。
3. **同通道跨日（同模态对照）**：现有实现保持不变。

界面必须能明确区分这三种类型，并让用户看出当前结果属于哪一类。

# 范围

- 修改 `app/change_detection_webui.py`（保持单文件、NiceGUI）。

# 约束与不变量

- 距离口径：d = (1 − cos) / 2，独立于 `distance_maps` 自带数值实现；后者仅用于读取 `common_mask`。
- `common_mask` 按传感器选取（view 前缀），不得跨传感器复用；同瓦片同传感器内所有 view 共用同一掩膜（53 组已验证）。
- 同一瓦片同一传感器内，各 view 的 `date_utc` 与 `parent_raw_index` 完全一致（同一次成像）。
- 数据规模：S2 33 瓦（32 两期 + V01 三期，67 epoch）；Landsat 20 瓦（12 两期 + 8 单期，32 epoch）；gallery 唯一键 98 条，仅 V01/sentinel2/2024-09-01 缺图。
- 数据集自带 C0/C1 为 1-cos 口径（= 2×d），已实测：C0_epoch_0 = 2×d(visible@t0, nir@t0)，C1_visible_before_ir_after = 2×d(visible@t0, nir@t1)，same_modality_visible = 2×d(visible@t0, visible@t1)。
- 跨模态残差存在方向不对称：d(A_t0,B_t1) ≠ d(B_t0,A_t1)，样本像素级最大差 0.06–0.31；对称化公式必须写入规格。
- 组合规模（只计四个严格单通道）：同日跨通道 594（S2 402 / LS 192）；跨日同通道 188（140/48）；跨日跨通道 282（210/72）；跨日类 45 个多期组。
- 组合规模（Q2 决策后，5 个视图可选，含 full）：同日跨通道 990（S2 670 / LS 320）；跨日同通道 235（S2 175 / LS 60）；跨日跨通道 470（S2 350 / LS 120）。
- 原 A1–A7 验收文字（A4 复验依据）：
  - A1：启动应用后，默认加载一个瓦片与视图，页面同时呈现该 view 两帧之间的变化热力图，以及与这两帧日期对应的 gallery 图像。
  - A2：热力图颜色由 d = (1 - cos) / 2 计算，取值与像素级计算一致，范围为 [0, 1]；任意像素的计算结果与直接用 numpy 对嵌入向量求 1 - dot 再除以 2 得到的值一致。
  - A3：页面上存在一个阈值控件，其量程为 (0, x]：x 由当前图像对自动计算并满足“阈值等于 x 时高于阈值的像素数为 0”，左端无法取到 0（最小值为一个步长）。拖动后无需刷新页面即可看到高于阈值的像素在热力图上被高亮，且滑块到顶时高亮数恰为 0。
  - A4：页面显示当前阈值下高于阈值的像素数量与占比，数值随阈值变化实时更新。
  - A5：切换瓦片或视图后，热力图与 gallery 图像同步更新，且显示的图像日期与该 view 所比较的两帧日期一致。

# 决策

- D1（用户确认，Q1）：跨日跨通道残差提供**两种视图**：带符号（默认）与绝对值。带符号视图使用发散色阶，负值表示该跨日期距离低于同日基线（通道差异减弱），正值表示高于基线（通道差异增强）；阈值、高亮与超阈值统计一律作用于 |残差|，界面必须写明该映射。
- D2（用户确认，Q2）：**允许 full 作为跨通道通道**。每个通道单独标注“分布内 / 分布外（波段消融诊断）”；当 A、B 分属不同分布类别时，界面标注“分布内 vs 分布外混合对照”。
- D3（用户确认，Q3）：跨日跨通道提供 **正向 / 反向 / 对称化 三视图**切换，默认对称化；统计区始终同时显示正向均值、反向均值、两者之差与对称化均值。
- D4（用户确认，Q4）：同日跨通道**保留**阈值高亮与超阈值统计；界面明示高值是通道差异基线，不代表变化。
- D5（实现选择）：同日跨通道使用单一共享帧选择器（该类型定义要求两通道同日期，选择器同时决定两通道帧）；跨日跨通道使用 A、B 两个帧选择器且要求日期不同；同通道跨日沿用现有帧对选择器。
- D6（实现选择）：跨通道默认 A=`sentinel2_visible`、B=`sentinel2_nir`（同传感器、均为严格单通道），回退到该传感器下按名称排序的前两个可用视图；跨日跨通道帧默认 A 首帧、B 末帧。
